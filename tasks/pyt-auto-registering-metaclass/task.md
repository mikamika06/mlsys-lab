## Context

A metaclass controls how Python creates classes. When a class statement is executed, Python calls the metaclass during construction of the class object.

A useful pattern is automatic registration: instead of manually adding every implementation to a list, the metaclass records each subclass as it is created.

For a class $C$, Python exposes its class name through $C.__name__$ and its qualified name through $C.__qualname__$. A registry can store entries of the form

$$
R[C.__name__] = C.__qualname__ .
$$

The registry is populated as a side effect of class creation.

## Task

Implement `build_registry()`.

Inside the function, create a metaclass that stores created subclasses in a registry. Define a base class and three subclasses using that metaclass:

- `JsonPlugin`
- `CsvPlugin`
- `XmlPlugin`

The function must return the registry dictionary generated by the metaclass.

Requirements:

- The registry must be updated by the metaclass during class creation.
- The registry keys must come from each class object's `__name__`.
- The registry values must come from each class object's `__qualname__`.
- Do not manually write the final dictionary.

## Example

```python
registry = build_registry()

# The returned values are generated from Python class metadata:
{
    "JsonPlugin": "build_registry.<locals>.JsonPlugin",
    "CsvPlugin": "build_registry.<locals>.CsvPlugin",
    "XmlPlugin": "build_registry.<locals>.XmlPlugin"
}
```

## What the gate checks

The gate builds a separate oracle using a real Python metaclass and class creation process. It compares the returned registry with the registry produced by the oracle.

A correct solution passes because Python itself generates the class metadata and the metaclass performs the registration.
