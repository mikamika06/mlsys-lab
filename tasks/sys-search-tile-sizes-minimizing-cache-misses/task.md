## Context

Compiler systems such as XLA and TVM choose schedules by searching over possible
tile sizes. A matrix multiplication can be divided into tiles so that frequently
used data stays in a small cache. A tile size choice affects the number of cache
misses even when the mathematical result is unchanged.

This task uses a simplified cache model. Memory is divided into cache lines. A
cache line holds `line_elems` consecutive elements. The cache contains
`cache_lines` lines and uses least-recently-used replacement.

For a tiled matrix multiplication with dimensions $M \times K$ times $K \times N$,
a tile $(t_m, t_n, t_k)$ computes output blocks by iterating over output tiles and
the reduction dimension:

$$
C_{ij} = \sum_k A_{ik}B_{kj}.
$$

The model counts misses while accessing the elements of $A$, $B$, and $C`. Lower
miss counts represent better schedules.

## Task

Implement:

```python
def choose_tile_sizes(M, N, K, cache_lines, line_elems, candidates):
    ...
```

Return a tuple `(t_m, t_n, t_k)` from `candidates`.

The arguments are positive integers. `candidates` is a list of tuples containing
possible tile sizes. Your function should select the candidate with the lowest
cache miss count under the provided cache model.

The cache model is a fully associative LRU cache. To compute misses, simulate the
memory accesses generated by tiled matrix multiplication:

1. Iterate output tiles over rows and columns.
2. Iterate reduction tiles.
3. Access the corresponding elements of the $A$, $B$, and $C$ tiles.

The returned tile must be one of the provided candidates.

## Example

```python
tiles = [(2, 2, 2), (4, 4, 1), (8, 1, 2)]
best = choose_tile_sizes(16, 16, 16, 32, 8, tiles)
# best is one of tiles and minimizes the modeled miss count
```

## What the gate checks

The gate recomputes the cache simulation independently and finds the optimal
candidate by exhaustive search. The returned candidate's modeled miss count must
satisfy

$$
\frac{\text{returned misses}}{\text{optimal misses}} \le 1.05.
$$

This checks that the implementation performs a real schedule search instead of
returning a fixed tile size.
