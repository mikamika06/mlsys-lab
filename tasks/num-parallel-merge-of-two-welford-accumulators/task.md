## Context

Welford's algorithm tracks a running population variance using a stable set of
statistics:

$$
n,\quad \mu,\quad M_2
$$

where $n$ is the number of observations, $\mu$ is the mean, and

$$
M_2 = \sum_{i=1}^{n}(x_i-\mu)^2 .
$$

These statistics can be computed independently on different chunks and merged
later. For two accumulators $(n_a,\mu_a,M_{2a})$ and
$(n_b,\mu_b,M_{2b})$, the Chan et al. parallel merge formula is:

$$
\delta = \mu_b-\mu_a
$$

$$
n = n_a+n_b
$$

$$
\mu = \mu_a+\delta\frac{n_b}{n}
$$

$$
M_2 = M_{2a}+M_{2b}+\delta^2\frac{n_a n_b}{n}.
$$

This allows parallel reductions of numerical statistics without concatenating
all original samples.

## Task

Implement `merge_welford(a, b)`.

The input arguments are tuples:

```python
(n, mean, M2)
```

where `n` is an integer count and `mean` and `M2` are floating point values.
The function must return a tuple:

```python
(total_n, merged_mean, merged_M2)
```

representing the combined population.

Use the Chan merge formula directly. The implementation must support empty
accumulators with $n=0$.

## Example

```python
a = (3, 2.0, 2.0)
b = (2, 5.0, 2.0)

result = merge_welford(a, b)
# (5, 3.2, 26.8)
```

The first accumulator represents the values $[1,2,3]$ and the second represents
$[4,6]$.

## What the gate checks

The gate creates random chunks, computes each chunk's Welford statistics, and
merges them with the candidate implementation. The reference is generated by
sequential Welford updates over the same values using NumPy float64 arithmetic.

The reported metric is the relative error:

$$
\mathrm{rel\_err} =
\frac{\lVert x-\hat{x}\rVert_2}{\lVert x\rVert_2+10^{-12}} .
$$

The candidate passes when `rel_err < 1e-11`.
