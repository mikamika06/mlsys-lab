## Context

The $k$‑Nearest Neighbour algorithm assigns to a query point $q \in \mathbb{R}^d$ the label of its closest training example.  
For $k=1$ this reduces to finding the single training vector $x_i$ that minimises the Euclidean distance
$$
\lVert q - x_i\rVert_2 = \sqrt{\sum_{j=1}^{d}(q_j-x_{ij})^2}\, .
$$

In a batch setting we are given a matrix of training points $X_{\text{tr}}\in\mathbb{R}^{n\times d}$, an array of corresponding labels $y_{\text{tr}}\in\mathbb{Z}^n$, and a single query vector $q\in\mathbb{R}^d$.  
The task is to return the label of the nearest neighbour.

## Task

Implement `knn_predict`:

```python
def knn_predict(X_tr: np.ndarray, y_tr: np.ndarray, q: np.ndarray) -> int:
    ...
```

* `X_tr` – 2‑D NumPy array of shape $(n,\;d)$.
* `y_tr` – 1‑D array of length $n$ containing integer labels.
* `q`   – 1‑D array of length $d$.

The function must return the label (an `int`) of the training point closest to $q$.  
Use vectorised NumPy operations only; avoid explicit Python loops. The returned type should be a plain Python `int`.

## Example

```python
import numpy as np
X_tr = np.array([[0, 0], [1, 0], [0, 2]])
y_tr = np.array([10, 20, 30])
q    = np.array([0.5, 0.5])

label = knn_predict(X_tr, y_tr, q)
print(label)   # → 10
```

The query is closest to the first training point, so its label `10` is returned.

## What the gate checks

A single gate named **exact_match** compares your output with a reference implementation that uses NumPy’s broadcasting and `argmin`.  
Your solution must return exactly the same integer for all test cases generated by the grader. No tolerance is allowed; any mismatch causes the gate to fail.
