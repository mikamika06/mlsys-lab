## Context

Creating a Python class executes several hooks in a defined order. A metaclass can customize namespace creation with `__prepare__`, receives the completed namespace through `__new__`, and can run additional initialization through `__init__`.

During `type.__new__`, Python also processes descriptors that define `__set_name__`. For subclasses, `__init_subclass__` is called before the metaclass `__new__` finishes.

The event sequence is observable because each hook can append a marker to a shared log. If $E = (e_1, e_2, \dots, e_n)$ is the event log, the task is to reproduce the exact sequence generated by CPython class creation.

## Task

Implement:

```python
def class_creation_events() -> list[str]:
    ...
```

The function must create an instrumented fixture class and return the ordered event log produced while that class is created.

The log entries must include:

- the metaclass `__prepare__` event
- the metaclass `__new__` event
- every descriptor `__set_name__` event
- the class `__init_subclass__` event
- the metaclass `__init__` event

Do not return a guessed ordering. The function should observe the class creation process by using the relevant Python hooks.

## Example

```python
events = class_creation_events()

# The exact order is produced by Python's class creation machinery.
assert events == [
    "prepare",
    "new",
    "set_name:first",
    "set_name:second",
    "init_subclass",
    "init",
]
```

## What the gate checks

The gate creates the same kind of instrumented class independently using the CPython class creation protocol and treats that execution as the oracle.

The returned list from `class_creation_events()` must exactly match the oracle event log. Any missing event or incorrect ordering fails the gate.
