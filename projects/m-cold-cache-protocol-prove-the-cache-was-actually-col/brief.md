We've noticed that several serving benchmark suites report unrealistically fast time-to-first-token (TTFT) metrics because their cold-cache benchmarking runs are polluted. In some cases, GPU memory allocations or prefix KV caches carry state across iterations, while in other cases, operating system host page caches hide true cold IO load during model startup or weight paging.

Your job is to build a cold-cache benchmark verification protocol. You will implement a validation harness that forces a clean state across host and device memory, runs inference requests under tracked cache conditions, and outputs verifiable diagnostic proofs (such as allocation generation tokens and cache hit counters). Finally, you will write regression tests to ensure that mock or incomplete cache-flushing procedures are reliably caught before benchmark results are published.
