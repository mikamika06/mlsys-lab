The profiling infrastructure for low-level ML systems currently lacks accurate mechanisms to measure real floating-point operations and compute efficiency for modern transformer blocks. During transformer evaluation runs on local hardware accelerators such as Apple Silicon MPS or general CPU targets, engineers cannot reliably verify whether reported performance metrics match theoretical peak specs.

Without a precise tracking mechanism leveraging PyTorch's native introspection tools, performance tuning becomes a guessing game. Engineers observe inconsistent training speeds and ambiguous throughput numbers without understanding the true FLOP breakdown of custom linear and attention layers. Furthermore, computing Model Flop Utilization (MFU) requires bridging the gap between raw hardware capabilities, active parameter counts, token throughput, and real execution FLOP counts.

Your task is to build a comprehensive profiling and estimation unit that accurately determines real FLOP counts using PyTorch's `FlopCounterMode`, computes reliable hardware MFU metrics based on measured token rates, and provides a robust testing framework to safeguard your performance metrics against regressions. You must implement the profiling package to measure real execution profiles, compute exact theoretical versus empirical execution ratios, and write a rigorous regression test suite that catches any faulty FLOP calculation logic.
