When building high-throughput serving runtimes using Ray Serve, managing request batching efficiently via the `@serve.batch` decorator is critical for maximizing GPU utilization and throughput. However, under high concurrency and specific configurations, engineers frequently encounter subtle behavioral issues where batching does not coalesce requests as expected, latency spikes unexpectedly, or synchronous execution blocks the actor event loop.

In this exercise unit, you will investigate and implement real request coalescing under Ray Serve's `@serve.batch` mechanism. You will build a testing harness and code structure to configure, sweep, and analyze batching parameters such as `max_batch_size` and `batch_wait_timeout_s`. Additionally, you will handle and reproduce the precise runtime exceptions that arise when mixing synchronous functions with asynchronous event loops or improper batch handling paradigms under Ray Serve. Ensure your implementations strictly adhere to Ray Serve semantics, handle edge cases cleanly, and provide robust regression tests to safeguard against breaking changes in batch coalescing invariants.
