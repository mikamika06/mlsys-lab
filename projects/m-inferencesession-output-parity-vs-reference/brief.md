We are observing inconsistent behavior and performance characteristics when deploying our ONNX-based model using the ONNX Runtime CPU Execution Provider in production environments. Specifically, downstream services have reported intermittent numeric discrepancies between our primary inference path and expected baseline outputs, raising concerns about potential numerical instability or precision loss during graph execution. Furthermore, system telemetry indicates unpredictable throughput bottlenecks when scaling CPU core allocations via session options. Operators have noted that adjusting thread counts does not yield the expected parallel efficiency, and pipeline profiling reveals uncertainty regarding whether graph optimization levels are correctly stripping redundant operators or fusing layers effectively. Engineers investigating the service degradation need a robust, deterministic validation harness to systematically verify output parity, analyze node reduction differences between basic and full optimization tiers, and characterize latency scaling behaviors across varying intra-op thread configurations before promoting builds to staging.
