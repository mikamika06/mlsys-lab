Our distributed training cluster is currently experiencing severe throughput degradation and periodic inter-node communication stalls when scaling up large language models across a 2x2 mesh topology using hybrid sharding strategies. During multi-node training runs, operators notice that certain physical interconnect links are heavily saturated with collective communication traffic, while adjacent links remain largely idle, causing severe job-wide load imbalance and unexpected synchronization delays. Furthermore, runtime memory profiling indicates that some model modules are failing to shard correctly or are triggering excessive fragmentation because their parameter wrap policy granularity is misaligned with the underlying execution block boundaries, leading to premature out-of-memory crashes on rank zero during gradient accumulation steps. When attempting to manually configure memory budgets and strategy selections, operators find that the system frequently picks sub-optimal sharding regimes, resulting in excessive communication overhead or immediate allocation failures. We urgently require a comprehensive diagnostic and simulation toolkit to analyze mesh traffic patterns, validate module wrap policies, and enforce correct sharding strategies under strict hardware memory budgets.
