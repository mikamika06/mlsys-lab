When scaling up large language models, activation memory during training frequently becomes the primary bottleneck that prevents scaling sequence lengths or batch sizes further, often outstripping model weights and optimizer states combined if un-managed. During the forward pass of transformer layers, numerous intermediate tensors—such as QKV projections, attention logits, dropout masks, and MLP intermediate activations—must be preserved in memory until their corresponding backward pass gradients are computed.

Engineers working on low-level memory accounting frequently encounter scenarios where out-of-memory errors occur unexpectedly long before theoretical hardware limits are reached, particularly during the transition from attention-dominated regimes to multi-layer perceptron-dominated regimes as sequence length varies. Without an exact analytical breakdown of per-layer memory footprints, it is impossible to predict the exact threshold where attention KV or intermediate activation tensors eclipse dense MLP states, nor can one accurately estimate the un-checkpointed memory footprint across arbitrary multi-layer architectures.

Your task is to implement a precise activation memory accounting module for transformer layers. You need to compute exact per-layer byte footprints given architectural dimensions and data types, determine the exact critical sequence length where self-attention memory surpasses MLP activation memory, and compute total un-checkpointed memory across all layers for real-scale configurations. Building this capability will provide deep insight into transformer memory dynamics and enable precise tuning of gradient checkpointing strategies.
