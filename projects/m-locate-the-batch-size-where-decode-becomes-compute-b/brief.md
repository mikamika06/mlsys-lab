Production LLM serving clusters frequently run into severe throughput degradation during the decode phase due to high memory bandwidth requirements and low arithmetic intensity, which leaves expensive GPU compute units underutilized. Conversely, prefill operations exhibit massive parallelism and can swing from memory-bound to compute-bound depending on prompt lengths and batch sizes.

Operations engineers running vLLM deployments are experiencing unpredictable performance bottlenecks and cannot reliably predict whether observed throughput drops stem from HBM memory saturation or compute limitations. Furthermore, teams lack analytical visibility into how dynamic workload parameters dictate operational regimes or how to back out achieved memory bandwidth metrics from production telemetry.

Your task is to implement an analytical roofline profiling module for vLLM serving. You will build algorithms to pinpoint the exact batch size where LLM decoding transitions from memory-bound to compute-bound, classify production workload profiles into operational regimes, and extract achieved HBM memory bandwidth from measured throughput statistics. Finally, you will write a robust test suite that catches regressions when roofline calculations are incorrectly bounded.
