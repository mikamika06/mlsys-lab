An inference server serving a custom transformer stack has started misbehaving under PyTorch's compiler diagnostics suite. The engineering team needs to audit a complex production run that combines multiple diagnostic captures from TORCH_LOGS into a single interleaved log stream, but standard tooling fails to pull out the structural telemetry reliably. Furthermore, local verification of compiled artifacts requires decompiling optimized kernels using depyf to ensure that the core function signature matches the eager-mode contract, followed by an exhaustive inventory of the files generated inside TORCH_COMPILE_DEBUG's debug directory.

Your task is to build a toolchain that parses this combined multi-artifact stream, extracts the required four metrics and fields, interfaces with depyf to decompile and verify the target resume function's exact signature, and systematically enumerates and catalogs the debug-directory contents produced by TORCH_COMPILE_DEBUG. You must implement the library modules, ensure correct handling of edge cases in the diagnostic artifacts, and provide a regression test suite that catches regressions where invalid fields or improperly structured debug outputs are returned.
