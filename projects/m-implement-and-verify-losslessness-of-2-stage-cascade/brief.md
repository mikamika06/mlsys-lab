Our downstream evaluation pipeline reported statistical distribution drift when deploying speculative decoding with multiple draft models. Tokens produced by the new multi-stage serving setup no longer match the ground-truth target model distribution on validation benchmarks, resulting in degraded output quality and failing perplexity regression tests. Additionally, performance monitoring shows unpredictable latency spikes in production clusters: enabling a second draft model cascade stage frequently increases overall per-token latency compared to single-stage speculation or direct target generation under non-optimal acceptance rates. Furthermore, multi-candidate draft proposals are occasionally dropping high-probability target tokens during multi-draft selection steps, causing subtle semantic shifts in generated responses. We need to implement mathematically verified lossless acceptance rules for both 2-stage cascaded speculation and K-draft multi-model generation, alongside an exact latency cost model to determine when cascading yields a true net throughput win before enabling these multi-stage pipelines in production environments.
