Engineers on the PyTorch runtime team are currently investigating erratic performance metrics reported by automated benchmarking harnesses. When evaluating model execution times, particularly under `torch.compile()`, the initial runs consistently include graph compilation and kernel optimization overhead. This distorts the sample distribution, making standard metrics like the arithmetic mean highly sensitive to outliers while masking true steady-state performance. Furthermore, when comparing baseline architecture A against optimized variant B using paired execution samples, standard Gaussian confidence intervals fail to capture the underlying bimodal latencies caused by dynamic shape dispatching and memory caching behaviors.

Your task is to implement a robust benchmarking and statistical analysis library that correctly excludes compilation time during warm-up phases, computes reliable summaries for bimodal distributions using robust statistics, and calculates paired bootstrap confidence intervals for precise speedup estimation. You must also supply a comprehensive test suite in the regression module to guarantee that statistical estimators remain invariant under expected analytical perturbations and correctly catch invalid confidence interval boundaries.
