Our team is investigating the performance bottlenecks of large language model inference workloads using NVIDIA Nsight Systems (nsys) sqlite export reports. Specifically, we need to extract fine-grained execution metrics from raw CUPTI and NVTX range tables to understand exact GPU time allocations per high-level semantic region.

Currently, when we inspect raw profiling databases exported from nsys, the correlation between NVTX ranges (which delineate user-defined application phases like attention, MLP, or specific layer executions) and the underlying hardware GPU kernel launches is non-trivial. Because NVTX ranges exist on host CPU timelines and GPU kernels execute asynchronously on device streams, simply associating kernels by naive time ranges or global ordering leads to significant inaccuracies, overlapping misalignments, and incorrect attribution of execution duration.

Furthermore, engineers frequently need to reproduce standard aggregation summaries—such as the exact metrics reported by built-in profiling utilities like cuda_api_sum or kernel summary tables—directly from raw CUPTI trace rows (calculating exact counts, total durations, averages, minimums, and maximums), as well as isolate the top hardware execution kernels by total active time and compute their precise percentage share relative to the grand total execution time.

Your task is to implement a robust low-level profiling module that ingests raw SQLite trace representations, performs precise timestamp-overlap joins between host NVTX ranges and device kernel timestamps, computes top kernel breakdowns, and accurately reproduces standard CUPTI statistical aggregations without relying on high-level proprietary tools.
