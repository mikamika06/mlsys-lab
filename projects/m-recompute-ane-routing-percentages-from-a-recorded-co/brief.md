Symptom report: Engineers working on edge machine learning pipelines have observed significant discrepancies during model profiling and deployment validation on Apple Silicon hardware targets. Specifically, performance dashboards and diagnostic tooling report incorrect or missing hardware execution metrics when ingesting recorded Core ML profiler export logs, showing zeroed or inverted allocation percentages across available processing units such as the Apple Neural Engine, CPU, and GPU. Furthermore, automated compilation pipelines wrapping the Core ML compilation utilities frequently encounter packaging errors where output directory structures fail downstream validation checks because expected artifact components are missing or misconfigured in the deployment bundle. Finally, latency estimation reports generated from execution cost data fail to correlate with empirical runtime measurements gathered from physical devices, introducing severe drift into automated compute-unit dispatch decisions and leading to suboptimal hardware utilization during high-throughput inference workloads across multiple edge configurations.
