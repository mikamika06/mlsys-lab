# Ticket: Investigate Blockwise Quantization Storage and Error Anomalies in Fine-Tuning Pipeline

## Symptom
During recent experiments integrating low-precision bitsandbytes-style blockwise quantization into our model weight inspection tool, we noticed unexpected behavior when evaluating the fidelity of compressed weights. Specifically, when we analyze a real linear layer weight tensor using blockwise quantization across varying block sizes, the reported storage-versus-error trade-off metrics appear inconsistent.

When configuring smaller block sizes (such as 32 or 64 elements per block), the memory footprint calculations diverge from the expected bit-width ratios, while larger block sizes (such as 512 or 1024) show catastrophic spikes in reconstruction error that do not align with standard theoretical bounds. Furthermore, when computing the mean squared error between the original real weight tensor and its blockwise dequantized counterpart, the evaluation script occasionally produces NaN or negative error values under certain block configurations. Engineers attempting to profile memory savings versus quantization degradation are currently unable to reliably sweep block sizes or verify whether the quantization implementation correctly scales values per block. We need a robust implementation that correctly handles blockwise absolute-max scaling, computes precise storage costs in bytes, and accurately evaluates reconstruction error without numerical instability.
