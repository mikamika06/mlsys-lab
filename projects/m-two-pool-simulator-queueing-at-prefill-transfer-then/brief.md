Our distributed vLLM serving infrastructure, utilizing a disaggregated prefill-decode architecture with dedicated connector layers, is experiencing severe tail latency spikes and transient stalls during high-concurrency traffic bursts. Operators report that requests submitted to the cluster undergo unpredictable delays where prefill instances complete initial computations successfully, but the subsequent key-value cache transfer phase bottlenecks or blocks the pipeline before decode workers can schedule the requests. Additionally, cluster deployment manifests using `--kv-transfer-config` JSON files are frequently prone to subtle configuration errors—such as inconsistent global ranks, omitted role definitions, or mismatched connector protocols—which bypass initial sanity checks and result in catastrophic worker crashes or silent hangs during cluster startup.

Furthermore, when the underlying NIXL metadata server experiences transient network partitions or process failures, the current operational tooling lacks a systematic way to analyze and isolate the blast radius, leading to cascading failures across unaffected worker pools. Your task is to implement a complete, robust simulation and validation suite to diagnose and resolve these issues. Specifically, you must build a two-pool pipeline simulator modeling prefill queueing, network transfer, and decode scheduling; a configuration validator for key-value transfer settings; and a fault analysis and regression testing framework that accurately characterizes metadata server failure modes and isolates their operational impact.
