When deploying large language models locally on Apple Silicon using `mlx-lm`, speculative decoding offers a promising route to higher generation throughput by pairing a compact draft model with a dense target model. However, configuring this setup correctly requires navigating subtle performance trade-offs. Practitioners frequently observe that naive choices for the lookahead window—controlled via `--num-draft-tokens`—fail to yield the expected speedup, and in certain configurations (such as when combining Mixture of Experts target architectures with draft models), severe throughput regressions can materialize instead of gains.

This unit requires you to analyze real speculative execution mechanics in `mlx-lm`, implement a harness to evaluate throughput ratios across different draft token sweeps on Apple Silicon hardware profiles, and diagnose the architectural regression associated with MoE speculative decoding. You will build modules to measure end-to-end token generation speedups, find optimal lookahead parameters, and encode a robust regression test that flags performance degradations.
