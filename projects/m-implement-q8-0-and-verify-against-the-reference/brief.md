An older quantization format used across various GGUF-compatible inference runtimes needs to be fully understood, implemented from scratch, and rigorously analyzed in Python.

When attempting to load and dequantize legacy blocks for older model weights, the current system fails to correctly interpret the bit layout, byte stride, and scaling factors of Q8_0 and surrounding formats. Specifically, naive block decoding attempts result in severe numerical drift, incorrect block sizing calculations, and a complete lack of comparative profiling across alternative legacy types. This causes downstream kernel mismatch errors, incorrect memory footprint estimations, and unverified quantization error metrics when inspecting model weights.

Your task is to build a complete pipeline that correctly implements Q8_0 block serialization and deserialization, derives structural storage properties across legacy types, and computes reconstruction fidelity rankings using root mean squared error against unquantized references. The implementation must follow strict vectorization and modular design principles, providing robust testing and verification safeguards to ensure absolute numerical correctness under arbitrary weight matrices.
