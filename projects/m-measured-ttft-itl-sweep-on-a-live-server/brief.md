We are experiencing severe tail-latency spikes and throughput degradation in our live serving environment when large requests are processed alongside normal conversational prompts. Specifically, when a large 128k context request enters the pipeline, it induces massive head-of-line blocking that stalls the decode iterations for all concurrent short requests, shooting up Time to First Token (TTFT) and Inter-Token Latency (ITL) metrics dramatically.

We need to instrument, measure, and analyze this TTFT/ITL sweep behavior on a live server simulation under concurrent load. The investigation must quantify the exact decode stall duration caused by a single 128k prompt and verify proper alignment of prefill chunk boundaries to block boundaries to mitigate memory fragmentation and alleviate scheduling pressure. You will build a benchmarking and profiling utility that models live server sweeps, measures latency ratios, computes head-of-line blocking metrics, and validates boundary alignment invariants.
