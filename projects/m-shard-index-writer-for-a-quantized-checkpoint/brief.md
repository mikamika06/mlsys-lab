When saving or inspecting large-scale quantized machine learning checkpoints, model weights and auxiliary tensor states are frequently split across multiple shard files to manage storage limits and parallel transfer streams. To load these files correctly without parsing every binary weight shard during initialization, serving engines rely on an index structure that maps individual tensor names to their corresponding physical shard files, byte offsets, data types, and quantization metadata.

Recently, during deployment pipelines on multi-node clusters, the model initialization phase has begun failing intermittently when loading checkpoints produced by custom quantization pipelines. While the binary shard files containing the quantized tensors are written correctly and contain valid weight data, the accompanying index files are failing validation or missing critical fields required to reconstruct the quantized layers. Specifically, tensor lookup requests during the index parsing stage either raise key errors or incorrectly associate quantized weight blocks with wrong shard paths, causing downstream tensor deserialization routines to crash before weight tensors can be loaded into memory.

Your task is to implement a robust shard index writer for quantized checkpoints that correctly processes, validates, and serializes the metadata mapping for multi-shard quantized model checkpoints. You will need to implement the underlying serialization logic, compute accurate byte offsets and length ranges for each shard, and provide a comprehensive regression test suite that catches structural index corruption, missing tensor mappings, and invalid byte boundaries.
