Ticket #BNB-882: Investigation of Mixed-Precision Quantization Discrepancies in LLM.int8() Emulation

During recent evaluation runs involving low-precision inference pipelines, engineers noticed unexpected numerical divergence when executing matrix multiplications using simulated eight-bit vector-wise quantization routines. Specifically, downstream perplexity metrics drift outside acceptable tolerances whenever large activation outliers are processed through standard uniform quantization blocks without proper mixed-precision decomposition.

Although the high-level transformer layers execute successfully under full precision, introducing custom vector-wise scaling factors and separating outlier dimensions into a separate high-precision sub-matrix causes intermediate tensor shapes and values to mismatch expected reference outputs. Operators report that relative error spikes significantly during linear projections in dense attention blocks, indicating that the column-wise or row-wise thresholding logic fails to isolate extreme magnitude values accurately or compute the mixed-precision matrix product correctly.

We need a robust implementation of the bitsandbytes-style mixed-precision decomposition and matrix multiplication routine within our local simulation package. This implementation must correctly identify outlier features based on magnitude thresholds, quantize the remaining elements into signed eight-bit integers with appropriate scaling factors, perform the mixed-precision matrix multiplication combining the integer product and the high-precision outlier residual, and verify numerical fidelity against a controlled reference oracle. Additionally, comprehensive regression tests must be established to ensure that invariants regarding scale factors and outlier retention are strictly enforced.
