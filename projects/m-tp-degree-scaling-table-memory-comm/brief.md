# Distributed Training and Inference Performance Degrades under Tensor Parallelism Scaling

## Symptom Report

When attempting to scale up tensor parallelism (TP) degrees across our multi-node cluster for large language model workloads, the system exhibits severe performance degradation and unexpected memory allocation anomalies. Specifically, when configuring models with higher TP degrees (such as TP=8 or TP=16), profiling traces indicate that inter-node communication overhead dominates execution time, while the expected linear reduction in per-GPU memory footprint fails to materialize correctly in several layers. Furthermore, baseline correctness checks on distributed linear operators show numerical divergence and incorrect activation accumulation patterns when execution is distributed across non-power-of-two ranks or unconventional shard sizes.

Engineers report that the current implementation of the tensor parallelism scaling table generates inconsistent weight memory and communication volume estimates compared to theoretical hardware models. Additionally, the row-parallel linear layer wrapper produces corrupted outputs during forward passes due to improper handling of sharded weight matrices and missing synchronization primitives. Finally, automated selection of the optimal TP degree fails to identify the hardware sweet spot, often picking configurations that maximize communication latency rather than balancing compute intensity and memory bandwidth. A rigorous restructuring and verification suite is required to correct these distributed systems modules.
