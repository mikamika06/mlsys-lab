Ticket #8492: Production FP8 E4M3 Inference Accuracy Regression on Outlier-Heavy Workloads

During recent validation runs of our low-precision large language model serving pipelines using FP8 E4M3 weights and activations, we observed catastrophic numerical degradation and sudden NaN or extreme saturation spikes specifically within intermediate feed-forward network layers during high-throughput inference bursts. While static calibration profiles generated during offline calibration work well for stable input distributions, highly dynamic token sequences cause severe activation outliers that completely overwhelm fixed boundaries. Conversely, naive per-token dynamic scaling introduces excessive quantization noise when activation distributions exhibit sparse, heavy-tailed properties where a tiny fraction of values dictate an overly wide clipping threshold, destroying resolution for the bulk of the tensor. Furthermore, recent debugging sessions revealed subtle operator errors where scaling factors are inverted during runtime transformations, turning quantization multipliers into divisors and corrupting tensor magnitudes beyond recognition.

We need a robust implementation within our low-level quantization library (`quantlib`) to properly analyze saturation fractions, compute MSE-optimal scaling factors under various clipping bounds, automate the decision logic between static and dynamic activation scaling regimes based on variance profiling, and reliably detect inverted scale applications before they propagate through the computational graph.
