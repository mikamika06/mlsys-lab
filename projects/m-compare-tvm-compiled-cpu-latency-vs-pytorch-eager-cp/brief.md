Right now, the benchmark pipeline fails to handle unsupported operator constructs during frontend ingestion, lacks accurate micro-benchmarking logic to compute stable latency ratios, and lacks robust test coverage against invalid frontend assumptions.

Your task is to fix the latency benchmarking harness and TVM ingestion pipeline. You will capture and isolate operator support failures during Relax import, implement a precise CPU execution benchmark comparing PyTorch eager time against TVM compiled module execution time, and write regression tests that verify improper frontend conversions are caught before benchmarking begins.
