An engineer in the ML infrastructure team is attempting to fine-tune a model using QLoRA via bitsandbytes and PEFT, but suspects that full-model fine-tuning is accidentally occurring instead of proper parameter-efficient tuning. When executing a 20-step training loop on a small transformer model, the downstream weight checks fail to confirm that only the low-rank adapter parameters are being updated, while base model weights are incorrectly accumulating gradient updates and experiencing drift.

The objective is to implement a robust training pipeline, set up proper quantization and PEFT configuration, execute a 20-step fine-tuning run, and implement a rigorous verification harness that asserts base model weights remain completely frozen, base model gradients are explicitly disabled or zero, and only the inserted LoRA adapter parameters change throughout the optimization process. A failure to correctly freeze the backbone results in silent full-parameter updates which violates the memory and checkpoint constraints of the training target.
