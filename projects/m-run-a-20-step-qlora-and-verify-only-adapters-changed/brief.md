During our recent fine-tuning runs using quantized base models and adapter-based parameter efficient tuning, validation metrics indicate unexpected drift in the core model representations. Engineers report that after executing a standard 20-step training loop intended to optimize solely the low-rank adaptation matrices, downstream evaluation shows unexpected degradation in baseline zero-shot capabilities. Inspection of the checkpoint parameter differentials reveals that floating-point updates are being applied indiscriminately across both the quantized base layers and the adapter weights, violating the core premise of parameter-efficient fine-tuning where foundational weights must remain strictly frozen. The training harness currently lacks automated verification to guarantee that base weights remain untouched throughout the optimization process, leading to silent regression in foundational model stability. We need a robust implementation that executes the 20-step fine-tuning loop correctly, isolates gradient updates exclusively to the adapter parameters, and includes a comprehensive regression test suite to catch any accidental unfreezing or global parameter modification before deployment.
