When exporting compressed low-bit models for edge runtime environments, engineers frequently observe a sharp drop in downstream task performance or unexpected floating-point reconstruction discrepancies after weight palettization. Specifically, models converted via standard uniform quantization pipelines exhibit high error spikes in layers with widely varying channel magnitudes. When attempting to unpack lookup-table compressed weights back into standard floating-point representations during model initialization, execution traces show severe numerical drift and out-of-bounds index lookups. Furthermore, evaluating different bit-widths through automated Pareto sweeps fails to correctly identify optimal memory-versus-accuracy trade-offs, leading to bloated model sizes or unacceptably high reconstruction loss. This project requires implementing robust per-channel scaling priors, precise lookup table decoding routines for compressed weight tensors, and an exhaustive bit-width Pareto sweep mechanism to ensure reliable edge execution.
