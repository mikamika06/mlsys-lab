We are experiencing critical Out-Of-Memory (OOM) faults during the training of large transformer models with high layer counts, specifically when attempting to scale context lengths and batch sizes. During our recent training runs on deep architectures with $L$ layers, keeping all intermediate activations in memory for the backward pass (full activation saving) causes GPU memory consumption to scale linearly with depth, which quickly exhausts available VRAM. Conversely, disabling activation checkpointing entirely prevents us from scaling to reasonable sequence lengths due to catastrophic memory footprints.

We need a robust low-level mechanism and analytical framework to derive, evaluate, and implement selective checkpointing strategies, including the sqrt(L)-optimal checkpointing scheme. Your task is to implement the core derivation and evaluation functions in the library to calculate peak activation memory under none, full, and sqrt(L) checkpointing strategies, find the optimal checkpoint segment size that minimizes peak memory, and compute the exact recompute-FLOPs overhead ratio for a given checkpointed segment configuration. You will also write a regression test suite that validates the correctness of your analytical implementations and successfully catches injected logic regressions in memory or segment size calculations.
