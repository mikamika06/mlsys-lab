We are implementing low-level mechanics for N:M semi-structured sparsity (specifically focusing on 2:4 sparsity), which enforces that within every contiguous block of four elements along a given dimension, at most two elements can be non-zero. Our current deployment pipeline is failing because upstream model pruning passes sometimes emit weight tensors or sparse masks that violate the strict 2:4 structural constraint or have incorrectly packed bit layouts, leading to hardware execution faults on custom tensor cores.

When these malformed tensors or unstructured sparse masks are passed directly down to the execution kernels, the low-level GEMM accelerators either crash, trigger illegal instruction exceptions, or silently produce corrupted outputs due to mismatched metadata index layouts. We need a robust constraint validation module that can ingest candidate sparse weight tensors or compressed mask arrays, verify compliance with the general N:M specification, accurately check real masks against these rules, and provide clear diagnostic information when blocks fail the sparsity criterion.

Your task is to build a complete validation and verification package for N:M sparsity constraints. You will implement functionality to validate raw weight blocks and sparse masks, unpack or check real execution masks according to the required block constraints, and provide comprehensive regression testing to ensure that any relaxation or misinterpretation of the N:M structural invariants is caught immediately before hitting the hardware runtime.
