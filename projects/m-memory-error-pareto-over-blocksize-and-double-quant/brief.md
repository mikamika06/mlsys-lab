Deployment pipelines targeting memory-constrained edge hardware are failing during large language model quantization sweeps. When engineers execute automated parameter searches across varying quantization blocksizes and enable nested double-quantization structures, the resulting memory footprints and mean-squared error trade-offs exhibit severe discrepancies. Current scripts either overestimate available headroom by omitting non-quantized modules such as token embeddings, layer normalization weights, and language model classification heads, or they fail to identify the optimal configuration that satisfies strict accuracy thresholds. Consequently, models are either deployed with excessive memory overhead or experience unexpected quality degradation due to unverified compression choices. This ticket requires implementing robust memory-error Pareto analysis, budget-constrained configuration selection incorporating argmin logic, and comprehensive footprint accounting that correctly incorporates non-quantized layers.
