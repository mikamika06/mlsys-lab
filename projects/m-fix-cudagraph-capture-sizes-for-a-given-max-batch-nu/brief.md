We are observing sporadic failures and inefficient allocation overheads when serving speculative decoding workloads under strict memory constraints in our inference engine integration layer. Specifically, the dynamic tensor shapes and variable generation lengths during speculative decoding passes cause CUDA graph capture to reallocate or fail due to unaligned or unpredicted batch configurations and capture sizes.

Additionally, when configuring SGLang with EAGLE speculative decoding over a shared KV-cache budget, operators are running suboptimally because the memory allocation plan fails to balance the draft-to-target compute ratio and verify step memory peaks accurately. Finally, when parsing verbose build logs exported from TensorRT-LLM during engine compilation, our tooling is unable to reliably extract and summarize draft-engine specific memory, layer count, and execution stats, leading to misconfigured runtime parameters.

Your task is to implement a robust low-level module that handles CUDA graph capture sizing for speculative decoding, computes throughput-optimal SGLang EAGLE configurations under strict KV-cache budgets, and parses TensorRT-LLM verbose build logs to extract accurate draft-engine performance metrics.
