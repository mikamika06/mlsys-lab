We are experiencing erratic mixed-precision behavior in a model featuring nested torch.amp.autocast contexts, specifically where outer and inner scopes conflict or where explicit `enabled=False` regions are nested within active autocast blocks. During a recent multi-GPU training run under PyTorch, certain sensitive normalization layers and embedding operations that were explicitly marked to run under disabled autocast conditions (`enabled=False`) unexpectedly inherited the precision state from an enclosing high-level autocast context. This leakage of cast state leads to unexpected type promotions, severe numerical instabilities, and silent precision drops in intermediate feature maps that bypass expected FP32 preservation rules.

Your task is to implement a robust precision policy engine that correctly interprets nested autocast scopes, properly honors explicit `enabled=False` carve-outs within active mixed-precision regions, and tracks active casting states across nested context block boundaries. You will build a lightweight interpreter that simulates PyTorch autocast stack semantics, analyze state transitions across nested regions, and provide a regression test suite that guarantees correct isolation of disabled regions from parent cast scopes.
