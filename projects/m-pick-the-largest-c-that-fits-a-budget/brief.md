When deploying large language models with quantized Key-Value caches under strict memory limits, memory management can become a significant bottleneck. In our current implementation of the low-level GGUF and llama.cpp integration routines, context sizing often fails to respect strict memory budgets, leading to out-of-memory errors during long context inference runs. Specifically, when attempting to maximize the context window parameter `-c` under a fixed VRAM budget, the allocation logic fails to account for non-uniform quantization configurations, memory overheads from mixed precision layers, and the strict byte alignment constraints required by the underlying kernels.

Furthermore, engineers have observed performance anomalies when handling asymmetric key and value quantization types, as well as silent accuracy degradation when the attention kernels attempt to execute without proper flash attention support for quantized formats. We need to implement a robust budget solver that determines the optimal maximum context size fitting a given budget, validate the hardware requirements for quantized KV caches, and measure the fused-path penalties associated with asymmetric K/V types.
