When deploying large language models or low-level machine learning systems to production, managing storage footprint and memory overhead is crucial. Storing models in low-precision or compressed serialized formats can dramatically reduce disk space and download bandwidth, but it introduces subtle performance and memory trade-offs during loading and inference. Specifically, distinguishing between the on-disk compressed file size and the frozen (uncompressed or memory-mapped layout) size is vital for capacity planning. Furthermore, loading these models often entails contrasting load-time overheads across various serialization formats and correctly dequantizing weights back to standard precisions (such as fp16) while strictly bounding the quantization loss or numerical error.

In this project, you will build a low-level module to analyze and handle compressed versus frozen model save sizes, measure and compare load-time characteristics across formats, and execute precise dequantization routines back to fp16 while guaranteeing that reconstruction loss stays within rigorous error bounds. Your implementation must integrate seamlessly with our test harness and clear all designated milestones without relying on external native dependencies.
