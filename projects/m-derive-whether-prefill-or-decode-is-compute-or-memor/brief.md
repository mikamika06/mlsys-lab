Our high-throughput LLM serving infrastructure is experiencing severe performance anomalies during peak traffic hours, leading to cascading latency spikes and unpredictable request tail-latencies. When concurrent traffic surges with a mix of long-context prompt prefill requests and short interactive token generation queries, system operators report erratic Time-to-First-Token (TTFT) degradation and erratic Inter-Token Latency (ITL) jitter. Standard monitoring dashboards show that GPUs frequently experience under-utilization during prefill phases for moderate batch sizes, yet become completely bottlenecked on memory bandwidth during token generation, regardless of hardware specifications. Furthermore, when attempting to mitigate head-of-line blocking by enabling chunked prefill, batch composition fails to respect dynamic token budgets, resulting in scheduling stalls where prefill chunks starve ongoing decode iterations or vice-versa. We urgently require a robust analytical and simulation toolkit within the low-level serving module to correctly model roofline bottlenecks across prefill and decode regimes, simulate deterministic chunked-prefill batch allocations under strict hardware token budgets, and reliably parse execution logs to quantify TTFT and ITL differences between chunked prefill configurations.
