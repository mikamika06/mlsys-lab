An Apple Silicon cluster engineer is setting up a fast fine-tuning pipeline using `mlx-lm` for local on-device model adaptation. During initial dry runs with a lightweight Llama-family model configuration, the team notices a mismatch between the expected number of trainable parameters calculated via the standard LoRA rank and target projection formulas and the actual tensors stored inside the generated `adapters.safetensors` file. Furthermore, when running short iterative adaptation jobs using `mlx_lm.lora`, the training script exits successfully, but downstream evaluation reveals erratic behavior where the reported training loss occasionally plateaus or spikes instead of monotonically decreasing over the initial steps, indicating potential misconfigurations in either the target layer specifications, learning rate schedules, or gradient scaling logic within the custom wrapper scripts.

Your task is to build a self-contained module and verification harness that mathematically derives the exact expected trainable parameter count for specified target layers under Apple's MLX LoRA implementation, executes a controlled dry run or programmatic simulation of an adapter training loop using the `mlx_lm` interface, and inspects the resulting safetensors shape metadata along with validating that the recorded loss values conform to a stable decreasing trend. You must implement the library components, provide a rigorous reference solution, set up robust grading harnesses for each of the three milestones, and write a comprehensive regression test suite that catches regressions where parameter derivation formulas fail or training loss validation checks are bypassed.
