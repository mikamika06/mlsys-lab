We are evaluating linear quantization strategies for our model deployments but are struggling to find the right balance between compression size and accuracy degradation. Right now, we only have a per-tensor quantizer implemented, which completely ruins the accuracy of layers that exhibit severe outlier values.

Some engineers suggested switching to channel-wise (axis-0 / axis-1) or even group-wise block quantization, but we currently have no tooling to actually measure what that costs in terms of metadata overhead (scales and zero-points). Furthermore, our naive attempts at asymmetric quantization keep resulting in zero-points that don't match standard int8/uint8 mathematical conventions, meaning we can't reliably test the error profiles or drop them into standard runtimes.

We need a unified library that applies a single core quantizer implementation across four different granularities: tensor, axis-0, axis-1, and block-grouped. We also need a "ladder" function that outputs a clean comparison showing exactly how many bytes of metadata each granularity requires against its maximum absolute error on a sample tensor, so we can finally make data-driven decisions on our quantization policy instead of guessing.
