When running the low-precision micro-scaling kernels under the new FP4 format specification, engineers are observing unexpected numerical divergence and severe underflow/overflow artifacts in downstream attention blocks. Specifically, when converting activation tensors to the 4-bit E2M1 floating-point representation, the resulting quantized value set fails to match the expected hardware reference distributions, causing intermediate accumulation values to saturate prematurely or drop to zero unexpectedly. The system reports mismatched dynamic range bounds and incorrect rounding behavior during quantization passes across multiple transformer benchmark suites. Furthermore, existing regression test suites are failing to catch these subtle bit-pattern enumeration discrepancies, allowing invalid floating-point representations to propagate into the low-level quantization pipeline undetected. A robust, exact value-set enumeration and precise round-to-nearest quantization routine is required to ensure bit-exact parity with the hardware specification before deployment across accelerator nodes.
