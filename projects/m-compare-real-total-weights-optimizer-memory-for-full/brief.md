Although the active trainable parameter count drops dramatically when applying low-rank adapters to linear projection layers, the measured total memory allocation for combined model weights and optimizer states does not scale down proportionally as predicted by naive theoretical estimates. Engineers attempting to schedule multi-tenant training tasks find that the runtime allocation reports divergent memory footprints, failing to account for the exact byte overhead of optimizer states such as AdamW first and second moment buffers associated with frozen versus active parameters, gradients, and master weights. Consequently, automated capacity planning scripts miscalculate peak memory demands, leading to frequent runtime failures during gradient accumulation steps.
