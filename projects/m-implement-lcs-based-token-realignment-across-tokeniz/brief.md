Universal assisted decoding (UAD) allows a smaller draft model using one tokenizer to speculate tokens for a larger target model using a completely different tokenizer. When the tokenizers diverge in vocabulary or merge/split subwords differently, token streams drift out of alignment immediately, destroying speculative acceptance rates and stalling generation.

In this exercise, you are investigating cross-tokenizer universal assisted decoding pipelines where token streams must be dynamically aligned before verification. During speculative generation loops across heterogeneous tokenizers, sequence alignment mismatches cause the target model verifier to reject valid prefix continuations. The token realignment pass is currently too slow, introduces excessive latency overhead, and fails to handle overlapping subword boundaries correctly, leading to worse throughput than standard autoregressive decoding.

You need to build a robust realignment pipeline that uses Longest Common Subsequence (LCS) or dynamic programming alignment over token ID arrays or decoded character spans. Your solution must measure the true token acceptance rate under realignment, quantify the runtime overhead of the LCS matching pass, and evaluate whether cross-tokenizer speculative decoding provides actual speedups over same-family tokenizers or standard decoding under varying sequence lengths and vocabulary divergence.
