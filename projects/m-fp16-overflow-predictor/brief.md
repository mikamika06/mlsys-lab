An edge-export pipeline converting a large language model to fp16 encounters unexpected precision degradation and catastrophic numeric overflow during downstream execution on edge hardware constraints. When compiling models with mixed-precision layers, intermediate activations scale exponentially across certain attention blocks, causing premature saturation when mapped to standard half-precision floating-point ranges. Engineers observe that specific parameter groups exhibit extreme sensitivity to magnitude variations, yet standard profiling tools fail to pinpoint which exact sub-networks trigger the overflow cascades.

Your task is to design an fp16 overflow predictor and regression harness within the ml-systems edge export module. You must implement a reliable predictor that evaluates sensitivity rankings across model layers, identifies high-risk weight and activation tensors prone to exceeding maximum representable fp16 thresholds ($65504$), and constructs a rigorous golden-file regression harness to validate numerical parity between reference floating-point executions and constrained half-precision outputs. The solution requires three core components: an analytical overflow predictor based on dynamic range bounding, a sensitivity ranking metric generator, and a robust regression test suite that catches precision regressions and unsafe tensor transformations before model compilation.
