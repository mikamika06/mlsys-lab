When serving multi-turn chat applications or workloads with extensive system prompts and shared few-shot examples using SGLang, serving throughput and Time-to-First-Token (TTFT) can degrade significantly if prefix caching is misconfigured. Operators have reported intermittent performance regressions where consecutive requests with identical system prompts experience unexpectedly high latency and redundant re-computation of key-value states across attention layers. Specifically, disabling the automatic prefix caching mechanism via server flags leads to severe latency inflation, but quantifying this degradation accurately across varying prefix lengths and request concurrency remains challenging without a structured benchmarking harness. Your task is to implement the configuration launcher, compute the TTFT latency ratio with and without radix attention caching enabled, and ensure robust regression testing protects against faulty cache configurations.
