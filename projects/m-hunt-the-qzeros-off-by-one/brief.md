Engineers working on low-level model inference and quantized weight loading have noticed intermittent accuracy drops and output corruption when executing models quantized with grouped zero-points and column permutations. Specifically, downstream inference kernels running custom low-bit unpacking logic fail to align weight tensors properly when group indices (`g_idx`) are reordered or inverted during kernel dispatch. Furthermore, raw zero-point tensors loaded from quantized model checkpoints appear to suffer from a systematic offset, causing decoding layers to point to incorrect quantization buckets and produce severe arithmetic discrepancies. Compounding these layout challenges, different packing convention configurations exhibit unexpected storage footprint variations when aligning bytes to hardware memory block boundaries. Your task is to implement a robust quantization backend component that correctly resolves zero-point off-by-one errors, accurately applies and inverts group index permutations without data loss, and computes reliable byte-size comparisons across alternative packing structures.
