When building modern large language models, handling long contexts efficiently often requires extending the context window beyond the original training length using rotary position embedding (RoPE) scaling methods. In several production inference engines and model architectures, adapting the position indices dynamically or adjusting the base frequency parameter becomes necessary when serving prompts that exceed the pre-trained maximum sequence length.

Engineers working on low-level machine learning systems have observed that different scaling strategies—such as dynamic NTK-aware interpolation, YaRN (Yet another RoPE extensioN method), and the specific Llama-3 scaling formulation—compute their scaling factors, frequency bases, and interpolation parameters differently. When these parameter formulas are implemented incorrectly or mixed up across model configurations, models suffer from severe perplexity degradation or complete output collapse during long-context evaluation.

Your task is to implement the exact parameter formulas for dynamic-NTK, YaRN, and Llama-3 RoPE scaling methods. You will build a Python module that correctly computes the base frequencies, scaling factors, and factorized dimension-wise interpolation weights, ensuring full compatibility with reference implementations used in state-of-the-art transformer architectures.
