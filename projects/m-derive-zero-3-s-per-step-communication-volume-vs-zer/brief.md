# Ticket: ZeRO-3 Communication Volume and Partition Analysis

Engineering is reporting unexpected communication overhead during distributed training runs with DeepSpeed ZeRO-3, alongside confusion regarding memory savings compared to ZeRO-1. During scale-out tests on multi-node clusters, training throughput drops significantly faster than expected as the World Size increases. While our optimizer state and gradient partitioning are ostensibly active, the actual byte volume transferred across the network during backward and forward passes does not match our theoretical expectations for parameter gathering and reduction.

Furthermore, engineers trying to verify memory reduction claims are struggling to parse raw DeepSpeed initialization logs and runtime memory traces. Because parameter partitioning dynamically slices tensors across ranks based on world size and remaining padding, manually calculating per-rank memory footprints or validating whether the communication volume scales linearly or quadratically with tensor dimensions has become error-prone. We need a rigorous, deterministic module to derive exact per-step communication volumes for ZeRO-3 versus ZeRO-1, parse recorded execution logs to extract real per-rank memory reductions, and calculate exact parameter partition sizes from DeepSpeed initialization artifacts.
