# Ticket: Prompt Cache Slot Persistence and Concurrent Multi-Chat VRAM Allocation Failures

## Symptom description
During local server execution under multi-client loads involving four concurrent chat sessions, prompt caching mechanisms exhibit severe correctness and resource allocation failures. Specifically, when a prefix prompt cache is saved to a persistent slot and later restored for a subsequent request, the continuation tokens generated by the model diverge from the expected identical trajectory, producing corrupted text outputs or logical inconsistencies. Furthermore, when configuring slot sizing under strict VRAM budgets, the existing allocation strategy fails to properly balance the fixed parameter overhead against dynamic per-slot context lengths. Under four active chats, this results in memory allocation mismatches or severe memory fragmentation when comparing unified KV cache approaches versus dedicated per-slot allocations. Engineers report that cache slots either overwrite active prefixes prematurely or consume excessive headroom, violating expected capacity limits and breaking deterministic prompt reuse guarantees across server restarts or session switches.
