When deploying stateful core machine learning models with on-device key-value caches, engineering teams frequently hit performance bottlenecks during the prefill phase and experience memory spikes that lead to out-of-memory crashes on resource-constrained hardware. Specifically, when the KV cache update verification logic is decoupled from the runtime execution graph or implemented naively, the system suffers from unpredictable per-token latency disparities between stateful generation steps and stateless prefill phases.

Furthermore, moving the cache updates directly into the model representation often creates an unexpected peak-memory delta during allocation surges, failing to account for dynamic tensor reallocation overheads and memory fragmentation.

Your task in this exercise unit is to design and implement an end-to-end verification and caching module for low-level ML systems that correctly verifies prefill cache updates against an oracle, analyzes stateful versus stateless per-token latency characteristics under varied sequence lengths, and computes precise peak-memory deltas resulting from moving the KV cache directly into the compiled model graph. You will ensure that your implementation adheres to strict correctness invariants, avoids performance regressions, and passes all automated gate checks across three distinct milestones.
