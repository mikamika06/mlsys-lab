When running Mixture-of-Experts (MoE) models with CPU offloading via `--n-cpu-moe`, engineers observe unexpected performance cliffs and memory allocation errors during inference benchmarking. Specifically, adjusting the number of CPU-resident experts either fails to reduce VRAM consumption as expected or causes severe throughput degradation that does not correlate linearly with the expected offload ratio. Additionally, custom tensor override configurations fail to reliably pin specific expert weights to host memory, causing silent fallback to GPU execution or CUDA out-of-memory crashes under long-context workloads. Furthermore, predicting the required memory bandwidth for a target throughput tier currently relies on guesswork, leading to hardware bottlenecks where CPU-to-GPU PCIe transfer rates saturate before compute units are fully utilized. We need a robust programmatic analysis pipeline to sweep CPU expert counts, verify tensor placement flags, and analytically derive the required memory bandwidth requirements to stabilize mixed-device MoE serving pipelines.
