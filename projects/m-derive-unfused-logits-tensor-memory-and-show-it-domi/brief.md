When fine-tuning large language models using unsloth-style fused Triton kernels and memory-efficient cross-entropy techniques, engineers often encounter massive memory spikes during the backward pass if activations and logits are handled naively. Specifically, when computing standard cross-entropy loss over a vocabulary size in the tens or hundreds of thousands, materializing the full activation tensor of shape batch size multiplied by sequence length multiplied by vocabulary size requires an immense amount of high-bandwidth memory (HBM).

In practice, for standard LLM configurations with large context windows or high batch counts, this un-fused logits tensor easily dwarfs the memory consumed by the model weights themselves. This creates severe out-of-memory errors during training even when weight gradients and optimizer states comfortably fit within device limits. To mitigate this, practitioners implement vocab-chunked cross-entropy or custom fused Triton kernels that compute the softmax normalization denominator and loss components iteratively or in chunks without ever materializing the massive full logits tensor in global memory.

Your task in this exercise unit is to derive and verify the memory footprint of un-fused logits, quantify the precise memory reduction achieved by chunking the vocabulary dimension during cross-entropy calculation, and write a toy fused Triton kernel in interpret mode that computes the forward pass matching a naive PyTorch reference without exploding intermediate memory.
