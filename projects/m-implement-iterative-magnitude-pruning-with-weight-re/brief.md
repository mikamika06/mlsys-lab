We are implementing iterative magnitude pruning with weight rewinding for a lightweight neural network in numpy. A core requirement of model compression workflows is determining the stability of lottery tickets and locating the pruning sparsity cliff where accuracy degrades catastrophically.

Currently, our benchmark pipeline only supports crude one-shot pruning, which drops the bottom fraction of weights by absolute magnitude in a single step without recovery or rewinding. When we try to reach high global sparsity levels (such as 90% or 95%) using one-shot magnitude pruning, the model performance collapses completely, failing to recover even with continued fine-tuning.

We need to implement iterative magnitude pruning (IMP) with weight rewinding, allowing us to alternate between pruning cycles and fine-tuning epochs while resetting the surviving weights back to their initial values (or epoch-$k$ weights). Furthermore, we need a pruning-round sweep to dynamically evaluate accuracy across varying sparsity fractions, pinpointing the precise sparsity cliff where performance drops off a cliff. Finally, we need a complete test suite to safeguard our implementation against incorrect sparsity mask applications and faulty rewinding schedules.
