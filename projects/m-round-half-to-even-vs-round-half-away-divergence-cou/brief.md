We are observing subtle numerical drift and downstream accuracy degradation when exporting model weights and intermediate activations to edge runtime formats. Specifically, models utilizing custom post-training quantization pipelines exhibit discrepancies during tensor rounding stages where different backend operators implement divergent rounding semantics—specifically round-half-to-even versus round-half-away-from-zero.

Engineers have reported that standard export toolchains fail to flag these rounding mismatches, leading to unexpected accumulation of bias in low-bit weights. Furthermore, profiling indicates that certain requantization nodes dominate the execution graph latency, but current cost models lack a precise way to compute individual requantization node cost shares relative to total layer compute. Finally, automated graph checks frequently overlook incorrectly specified quantized dimensions in multi-axis tensor layouts, causing silent out-of-bounds memory lookups or incorrect scaling factor applications during runtime inference.

We need a robust module to analyze and quantify these issues: computing exact round-half divergence counts across given float arrays, evaluating the exact relative cost share of requantization nodes within a computation graph, and detecting incorrectly configured quantization dimensions prior to graph emission.
