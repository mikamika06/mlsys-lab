Our local inference serving infrastructure is experiencing criticaltail-latency regressions and throughput degradation when executing models under heavy, continuous streaming workloads. Profiling indicates that our static backend selection logic blindly favors TensorRT execution providers even when sub-graphs suffer from severe partial coverage, leading to excessive graph fragmentation, frequent host-device context switching overheads, and inefficient kernel dispatch patterns.

Furthermore, when deploying models characterized by high input shape volatility, the execution provider continuously triggers costly engine re-compilations, plan caching evictions, and compilation stalls that completely negate any static optimization benefits. We need a robust execution provider ranking and selection framework that dynamically evaluates p99 latency distributions, computes the exact penalty of partial graph fragmentation, and applies intelligent policy rules to bypass compilation-heavy backends when shape churn is high. Your task is to implement the core modules for execution provider ranking, fragmentation cost analysis, and adaptive backend selection policy, accompanied by a rigorous regression test suite.
