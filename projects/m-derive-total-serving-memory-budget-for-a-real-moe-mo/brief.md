We are experiencing severe out-of-memory errors and unexpected resource exhaustion when deploying our mixture-of-experts large language model in the production serving cluster under long-context workloads. Specifically, when user requests approach extended context lengths, GPU memory usage spikes unpredictably, leading to sudden node crashes and dropped inference streams. Our current operational tooling lacks an accurate way to forecast the precise memory footprint required for weights, activation buffers, and key-value caches across varying sequence lengths and expert configurations. Furthermore, operators are unable to analytically determine the critical sequence length where computational bottlenecks shift from feed-forward network routing computations to attention matrix operations, making it difficult to optimize batching and scheduling policies. Additionally, when attempting to profile real prefill and decode latency behaviors against increasing context sizes, our local evaluation scripts fail to produce consistent, reproducible latency measurements that correlate with theoretical expectations. We need a robust computational module to rigorously calculate serving memory budgets, analyze attention-versus-FFN crossover thresholds, and accurately model latency profiles under diverse operational constraints before deploying these models to production environments.
