When running complex PyTorch pipelines utilizing the MPS (Metal Performance Shaders) backend on Apple Silicon, certain low-level operators lack direct native coverage. A prominent example occurs during high-dimensional tensor transformations involving Fast Fourier Transforms, specifically hitting the `aten::_fft_r2c` operator. Instead of failing gracefully or falling back safely, operations can crash outright with a `NotImplementedError`, or worse, trigger a silent fallback to the CPU device behind the scenes. This silent fallback severely degrades execution performance and introduces data synchronization overhead across hardware boundaries without warning.

Your task in this exercise unit is to build a robust low-level handler within the `edge_mlx` framework. First, you will intercept and reproduce the `aten::_fft_r2c` `NotImplementedError` and implement a clean fallback fix. Second, you will replace an unsupported operator with an explicit, manual MPS-native implementation to avoid unexpected execution paths. Third, you will construct a profiling diagnostic tool capable of detecting silent fallbacks by diffing the device column of a recorded operator profiler against an all-MPS expectation. Finally, you must write a regression test suite that encodes these invariants to safeguard against regressions.
