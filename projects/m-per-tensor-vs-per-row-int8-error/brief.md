Our team is investigating the performance and accuracy trade-offs of applying int8 quantization to large language model layers using torchao. During our initial deployment phase, we observed significant degradation in output fidelity when quantizing certain weights and activations. Specifically, when we apply a naive per-tensor int8 quantization scheme to weights containing wide outlier distributions, the resulting mean squared error spikes dramatically compared to a fine-grained per-row or per-channel quantization strategy.

Furthermore, after successfully implementing the correct quantization configurations to satisfy our strict accuracy constraints, our engineers encountered a puzzling performance bottleneck: running standard eager-mode PyTorch inference with the quantized modules yields zero wall-clock speedup, despite reduced memory footprints and lower memory bandwidth requirements. The overhead of dynamic dispatch and Python interpretation completely masks any hardware acceleration benefits until the execution graph is fully compiled using torch.compile.

We need a robust suite of quantization utilities that can compute per-tensor versus per-row errors, select appropriate torchao configurations based on maximum tolerable MSE constraints, and enforce proper compilation strategies to ensure actual runtime speedups.
