Performance regression analysis in low-level machine learning serving systems often stalls when engineers attempt to diagnose production bottlenecks using raw, unstructured timestamp logs and hardware telemetry. In typical serving deployments, inference traces record request arrival times, token generation milestones, and completion events across hundreds of concurrent streams, yet operators lack a reliable programmatic pipeline to distill these logs into rigorous latency percentiles such as Time to First Token (TTFT) and Inter-Token Latency (ITL). Furthermore, capacity planning requires calculating exact Key-Value (KV) cache memory footprints per sequence given precise layer configurations, hidden dimensions, and data types, alongside determining the maximum concurrent sequence capacity under strict device memory constraints. Finally, evaluating hardware efficiency demands measuring decode throughput scaling ratios between batch size 1 and batch size 64 to uncover memory bandwidth saturation or compute bottleneck anomalies. Without a standardized, automated evaluation harness, debugging these performance characteristics manually leads to inconsistent metrics, inaccurate memory limits, and undetected throughput regressions during high-concurrency batch execution. This exercise provides the foundational modules required to ingest raw log traces, compute accurate latency distributions, model KV cache memory allocation boundaries, and analyze throughput scaling ratios cleanly and reliably.
