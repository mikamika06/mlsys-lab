When running importance matrix (imatrix) generation pipelines for Mixture-of-Experts (MoE) models across diverse calibration corpora, our downstream quantization and perplexity evaluations have revealed inconsistent quality and unexpected degradation. Specifically, certain calibration runs produce models with severe quantization artifacts in specific expert layers, while others show unusually uniform or sparse activation metrics.

Engineers report that standard validation checks fail to flag runs where the calibration set inadequately exercises the expert routing network, leading to zero-frequency or severely under-sampled experts in the generated imatrix. Furthermore, when comparing imatrices generated from different corpora (such as WikiText versus custom code datasets), we currently lack a robust programmatic way to quantify the divergence between their importance weights without manual inspection. Compounding these issues, interrupted or aborted imatrix generation jobs—due to preemption or timeout—frequently write partial output files that appear structurally valid to basic file-existence checks, yet are truncated mid-computation, silently corrupting subsequent quantization passes.

We need a dedicated analysis and validation module (`moecov`) integrated into our tooling suite to programmatically measure MoE expert coverage over calibration datasets, compare divergence metrics between dual imatrix files, and reliably detect truncated or incomplete imatrix run artifacts before they propagate into production quantization workflows.
