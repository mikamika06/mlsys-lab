Engineers report that deploying Mixture-of-Experts (MoE) models with quantized router weights causes severe token misrouting and unpredictable shifts in expert affinity. When models are compressed using standard Round-To-Nearest (RTN) quantization, the routing decisions fluctuate heavily compared to the unquantized baseline. Conversely, activation-aware methods such as AWQ or GPTQ aim to mitigate such distribution shifts, yet intermittent argmax flips still occur on tokens situated near the decision boundaries of competing top-k experts.

To resolve this issue in production, we need a rigorous quantitative framework. Specifically, the system must compute the exact routing weight quantization error metrics and contrast RTN against AWQ-style error bounds over real-world router weight matrices. Furthermore, we require a mechanism to analytically derive the router-logit-gap threshold that dictates when quantization-induced noise can trigger an argmax switch between the top competing experts. Finally, we must establish a robust safeguard test suite that catches any faulty threshold or routing simulation logic. Your task is to implement the core analysis routines, threshold derivation functions, and regression test suites to guarantee stable MoE routing under quantization.
