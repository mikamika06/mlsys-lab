# Ticket: Numerical Divergence in Edge Exported Model Layers

We have observed a growing discrepancy between the eager execution mode and the exported version of our multi-layer edge transformer model. During recent integration tests on edge hardware targets using the BundledProgram runtime wrapper, production inference outputs have begun to diverge significantly from our reference PyTorch execution after a specific depth in the network. While the overall end-to-end output sometimes passes basic tolerance checks, downstream tasks fail intermittently because internal activations exhibit unexpected numerical drift or NaN spikes.

Engineers report that manual debugging across dozens of sequential layers is extremely tedious and time-consuming. We need a robust programmatic utility within our low-level export pipeline to systematically compute the signal-to-noise ratio (SNR) layer-by-layer between eager outputs and exported artifacts. Furthermore, the tool must automatically isolate and bisect to the exact first layer where the numerical divergence exceeds safe operational bounds. Finally, we require verification routines for the BundledProgram structure alongside strict regression testing to ensure that future compiler optimizations or graph fusions do not silently break numerical parity at intermediate boundaries.
