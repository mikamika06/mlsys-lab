# Ticket: Production Serving Cluster Flakiness and Silent Output Drift

## Symptom Description
Our vLLM-based serving cluster has started exhibiting intermittent, non-deterministic output discrepancies across different dynamic batch sizes during peak load testing. Downstream applications consuming our LLM endpoints report that identical prompt inputs occasionally yield diverging token streams when concurrent request volumes fluctuate. Specifically, user monitoring dashboards highlight that exact-match golden tests fail intermittently, yet individual requests re-run in isolation pass consistently.

Compounding this issue, our nightly regression suite includes a batch of 12 historical output comparison samples that are currently failing manual categorization or failing to flag genuine regressions versus benign floating-point rounding changes or sampling noise. Engineers are struggling to reliably separate true generation bugs from harmless numerical drift caused by non-associative reductions in parallel GPU kernel accumulators. Furthermore, our automated model promotion pipeline lacks a rigorous perplexity-based upgrade gate on a frozen reference corpus using a deterministic CPU model, causing unverified kernel optimizations to slip into production. We need robust simulation utilities to quantify logit deltas from reordered sums, a precise classification framework for output diffs, and strict regression test guards to ensure cluster determinism and safe model upgrades.
