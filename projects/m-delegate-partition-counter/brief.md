When exporting neural network models to mobile edge runtimes such as Android NNAPI or TFLite GPU delegates, performance profiling reveals an excessive number of fallback round-trips between the CPU execution provider and the hardware accelerator. Specifically, runtime tracing of our production vision and speech models indicates that single continuous layers are fragmented into dozens of tiny sub-graphs and isolated partitions. This frequent execution handoff incurs severe CPU-GPU synchronization overhead, memory copying penalties, and cache thrashing, causing noticeable frame drops and latency spikes during real-time inference on target mobile devices. Furthermore, when comparing XNNPACK CPU fallback execution curves against the hardware GPU delegate across varying input resolutions and op configurations, the end-to-end latency profile exhibits irregular, jagged scaling rather than a smooth monotonic curve. This anomalous behavior correlates directly with high partition fragmentation counts across the computation graph. Engineering teams currently lack an automated mechanism to quantify these partition boundaries, identify specific boundary-breaking unsupported operations, and apply structural op substitution rules to consolidate contiguous delegated regions prior to final compilation and packaging.
