We trained our large language models using a fully sharded data parallel strategy, splitting the model parameters and gradients across a specific number of graphic accelerators to fit the huge memory footprint. We successfully saved our checkpoints at regular training milestones, expecting to easily resume the training process or fine-tune later. However, when we attempted to load these saved files onto a cluster configuration with a different number of GPUs, the initialization process inevitably crashed before any iteration could even begin.

The root cause of this failure lies in the rigid coupling between individual rank-local tensor shards and the specific count of original processes in the distributed group. Because each node stores only a fraction of the sharded weights or optimizer states, directly loading these shards onto a topology with a different rank count results in severe dimension mismatches, incorrect tensor slicing, and deserialization errors. Our prior training runs required significant computational time and financial investment, and halting further progress due to an inflexible checkpoint format severely blocks our deployment roadmap. We need to implement a robust utility to parse, merge, and convert these distributed FSDP checkpoints into a unified, portable format that allows seamless restoration across any arbitrary target device count without losing any precision or breaking the underlying parameter shapes.
