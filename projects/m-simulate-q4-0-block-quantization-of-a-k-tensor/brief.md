When deploying large language models with quantized key-value caches using llama.cpp formats, we have noticed that long-context generations experience sudden quality collapse and repetition loops. Analysis of the dumped memory states suggests that our custom low-level quantization pipeline fails to pack the cache tensors into the precise `q4_0` layout expected by downstream kernels. Specifically, block-wise scaling factors or 4-bit nibble arrangements are drifting from the target format, causing catastrophic numerical discrepancies during dequantization.

To debug and prevent this, we require a robust, bit-exact simulation module in pure Python that implements `q4_0` block quantization and dequantization. The simulation must handle tensor layout reshaping, block-wise maximum extraction, half-precision scale encoding, and 4-bit integer packing where pairs of quantized values share a single byte. Furthermore, it should provide precise calculation of maximum absolute errors across blocks to verify that the quantization distortion remains within acceptable theoretical bounds before any hardware deployment. Your task is to implement this simulation framework and provide a reliable test suite.
