Our distributed serving cluster is suffering from suboptimal decoding throughput and high generation latency when scaling tensor parallelism (TP) across multi-GPU nodes. During heavy concurrent request bursts with Grouped-Query Attention (GQA), certain tensor parallel degree choices severely bottleneck memory bandwidth or introduce excessive cross-device communication overhead during the small GEMV operations characteristic of the auto-regressive decode phase.

We need to implement a robust decode-latency model and a partition decision engine that reproduces DeepSpeed AutoTP's sweet spot selector. Furthermore, our KV-cache memory manager fails to correctly handle head-sharding under GQA when the tensor parallel degree does not evenly divide the number of key-value heads, leading to uneven slice allocations and alignment errors across ranks.

Your task is to build a decoding latency modeling tool, incorporate proper KV-cache head-sharding under GQA, and automate the tensor parallel partition decision engine. You must also write comprehensive regression tests that strictly verify these partition invariants and fail if invalid sharding bounds or sub-optimal sweet spots are chosen.
