# Device Memory Plan

The model exported successfully through ExecuTorch into a `.pte` program artifact, but when deployed to the target edge microcontroller, it immediately crashes with an out-of-memory error during execution. The default memory allocator allocates independent buffers for every intermediate tensor without lifetime overlap analysis, causing the peak memory footprint to greatly exceed the strict hardware SRAM budget available on the edge device.

Your task is to inspect the exported execution plan, analyze tensor lifetimes and memory reuse opportunities, separate static weights from transient activation buffers, re-plan the buffer allocation using interval coloring or lifetime overlap analysis, and ensure that the resulting peak memory footprint fits comfortably within the hardware device budget. Furthermore, you must verify that tensor reuse does not corrupt active data during operator execution phases. Finally, you will write robust regression tests to ensure that any future model changes or compilation updates are automatically checked in CI against memory budget violations.
