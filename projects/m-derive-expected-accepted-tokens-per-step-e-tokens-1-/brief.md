We are observing significant end-to-end latency regressions and highly unpredictable token generation throughput when running our speculative decoding serving engine under varying workload intensities and dynamic prompt distributions. During production stress testing, the empirical token acceptance rate deviates substantially from our analytical throughput projections, causing severe performance drops and fluctuating GPU utilization metrics across multi-node clusters. Furthermore, our offline profiling and validation pipelines report subtle numerical inconsistencies when evaluating modified rejection sampling implementations against reference distributions, which manifests as biased token distributions and occasional divergence in sequence quality during long-form generation tasks. Additionally, downstream debugging sessions are severely hampered because different worker nodes fail to reproduce exact token accept-reject traces when initialized with identical pseudorandom number generator seeds, introducing non-deterministic behavior that breaks regression testing suites and complicates root-cause analysis for rare edge cases. We urgently require a clean, rigorously tested core speculative sampling module that accurately models expected token yields, implements mathematically sound and lossless modified rejection sampling, and perfectly reproduces exact accept-reject decision sequences under deterministic seeding conditions.
