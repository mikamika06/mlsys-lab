During high-throughput continuous batch decoding in our inference pipeline, output text across active requests is suffering from severe cross-request corruption and silent memory safety violations. When requests finish generation and are removed from the active batch, subsequent decode steps produce output tokens containing text fragments and context from completed or unrelated requests.

Monitoring logs indicate that whenever request slots in the active batch are reordered or pruned (e.g., when sequence 0 finishes and sequence 1 shifts into slot 0), key and value tensor fetches for attention computation retrieve past tokens belonging to whichever request previously occupied physical slot 0 in the preallocated KV memory block. Additionally, newly generated key-value projection vectors are written into physical positions that do not match the target request's assigned memory block, overwriting valid cache states.

This issue manifests exclusively when requests complete asynchronously and batch size fluctuates dynamically between decode steps. We need a reliable mechanism to map dynamic active batch indices to static physical cache allocations and safely gather sequence history during attention key-value retrieval.
