Our serving pipeline for large mixture-of-experts models is hitting memory capacity limits on single GPUs during inference initialization, particularly when loading large quantized checkpoints. While GGUF Q4_K_M quantization is standard for reducing model footprint, we lack visibility into the exact memory distribution across tensor classes—specifically distinguishing between attention projections, router gates, and expert feed-forward networks—on a real mixture-of-experts architecture. Furthermore, when deploying these models under memory constraints, we observe unpredicted perplexity spikes and suboptimal accuracy trade-offs.

Specifically, engineers attempting to optimize memory usage by selectively quantizing components find that treating the entire model uniformly leads to severe degradation. We need a rigorous mechanism to inspect the fine-grained byte allocation of a GGUF Q4_K_M file across different tensor classes, quantify the perplexity delta when independently quantizing router blocks versus expert blocks, and construct a data-driven mixed-precision hot/cold expert quantization map derived from execution activation traces. Without this tooling, memory budgets are routinely exceeded or model quality is severely compromised due to naive quantization choices across heterogeneous MoE layers.
