We are running several local LLM configurations on consumer hardware under a strict memory footprint, and performance is falling short of our throughput targets. Recently, we deployed a quantized model pipeline, but the memory allocation and inference speeds are inconsistent across different GGUF tensor structures.

Specifically, when loading different tensor blocks, the memory reported by our runtime wrapper does not match the expected bytes-per-weight, leading to inefficient memory budgeting. Furthermore, when trying to fit decode tok/s against the effective bits-per-weight across three different quantization formats, the scaling curve behaves unexpectedly, causing suboptimal hardware utilization.

To make matters worse, when we attempt to choose between an 8-billion parameter model quantized to 8 bits and a 14-billion parameter model quantized to 4 bits under a fixed memory cap, the decision logic fails to account for the true effective bit-width and throughput trade-offs, resulting in incorrect deployment choices. We need a robust module to compute the exact effective bits-per-weight directly from GGUF tensor tables, fit the decode performance scaling accurately, and enforce correct model selection under memory constraints.
