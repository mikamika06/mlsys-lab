When migrating legacy TVM Relay models to the modern Relax IR framework, engineers frequently encounter unexpected discrepancies in intermediate representation node counts and constant-folding behaviors across standard three-operation graph topologies. During migration audits, teams report that compiled models exhibit different intermediate representation sizes than expected, sometimes scaling higher under Relax or failing to fold specific arithmetic subexpressions that were safely optimized out in Relay. This creates downstream pipeline stalls, unexpected memory footprint increases during lowering passes, and behavioral divergence when executing folded constants under different precision modes. Furthermore, numerical inconsistencies arise when constant folding drops or retains specific attributes differently between the legacy and modern stacks. Engineers must build an analysis module to compute accurate Relay versus Relax IR node counts for a set of standardized three-op models and reproduce the exact constant-folding discrepancy documented during compilation. Your task is to implement the core evaluation logic in the designated modules, ensuring all metrics match reference expectations and writing a robust regression test suite that catches faulty graph node calculations or incorrect constant-folding behavior.
