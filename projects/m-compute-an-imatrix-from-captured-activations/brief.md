Our downstream GGUF quantization workflow is producing degraded model output when running on low-bit target formats (such as Q3_K_M and Q4_K_M). Investigation indicates that the importance matrix (imatrix) files generated during calibration are inaccurate, causing key projection matrices to be quantized with suboptimal weight scaling.

When activation data is captured across multiple dataset chunks, the resulting imatrix files show inconsistent activation counts and unexpected value scales across layers. In some runs, merging imatrix outputs from parallel calibration workers yields results that differ drastically depending on the order of execution or worker shard sizes. Furthermore, when feeding small test models through the quantization pipeline, invalid imatrix structures—such as missing layer keys, zero-count entries, or mismatched hidden dimension shapes—pass through without early validation, leading to runtime crashes deep inside the quantization pass.

We need a standardized library to reliably compute per-layer importance matrices from captured activation tensors, merge multi-chunk imatrix files with proper sample-count weighting, and run an end-to-end execution and validation check for small model runs. A regression test suite must also be included to catch improperly weighted imatrix merges.
