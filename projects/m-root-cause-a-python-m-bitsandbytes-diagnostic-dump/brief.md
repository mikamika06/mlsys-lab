Your team needs to diagnose and remediate this failure in the low-level library loading and diagnostic inspection subsystem. 1. Parse and root-cause structured diagnostic dumps generated by `python -m bitsandbytes`, extracting exact failure modes, library search paths, and missing symbols.
2. Implement a traceback triage classifier that maps runtime error signatures and dynamic linker exceptions to specific root causes (e.g., CUDA version mismatch, missing libcudart, or incorrect shared-object naming).
3. Build the shared-object name resolver that computes the exact dynamic library filename (`libbitsandbytes_cuda*.so`) matching the runtime parameters, complete with a rigorous test suite that fails if the resolution logic breaks under edge cases.
