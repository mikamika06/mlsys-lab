Clients have reported intermittent and frustrating behavior in our chat service: identical user prompts occasionally return divergent responses across execution runs, whereas direct execution via the Ollama CLI produces perfectly consistent and identical output. Automated regression tests tracking output stability fail approximately once every five runs, signaling non-deterministic behavior creeping into the generation pipeline. Investigation reveals that configuration parameters such as random seeds, sampling temperatures, and token prediction limits fail to propagate correctly from per-request payloads down through the API layer and the underlying model definitions. This exercise unit requires establishing a rigorous option precedence hierarchy (Modelfile configuration overridden by API defaults, which are in turn overridden by per-request parameters), properly forwarding all required inference parameters to the runner engine, enforcing strict determinism for generation runs, and ensuring that ten consecutive identical queries produce byte-for-byte identical output hashes. Finally, robust regression tests must be implemented in the repository to catch any future regression or configuration desynchronization instantly.
