When running automated model selection scripts on our distillation sweep, the model selection pipeline fails to filter out strictly dominated checkpoints, occasionally selecting bloated checkpoints that have lower accuracy and higher parameter counts than smaller alternatives, causing our deployment runner to fail quality gates in production. Specifically, the automated compression evaluation framework frequently picks larger student model variants even when a much smaller student configuration achieves equal or superior downstream validation accuracy. Engineers have reported that when analyzing multiple compressed checkpoints generated across various pruning and distillation ratios, the selection tooling returns non-optimal trade-off points. This misbehavior breaks downstream packaging scripts that expect only Pareto-optimal configurations to be bundled for edge deployment. Furthermore, accuracy retention calculations against teacher outputs currently exhibit erratic ratio behaviors when logits have unexpected shapes or zero denominator cases, leading to pipeline crashes during nightly regression testing. We require a robust implementation to correctly compute the Pareto frontier over parameter and accuracy metrics, accurately measure retention against teacher baselines, and validate checkpoint optimality across multiple trained artifacts.
