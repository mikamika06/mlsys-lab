We noticed a severe mismatch between theoretical parameter removal and wall-clock inference speedups when applying structured pruning to convolutional neural networks using dependency graphs. When deploying a popular CNN architecture for edge execution, the upstream layers and residual branches were pruned using a sparsity ratio constraint, but the resulting execution trace showed negligible latency reduction. Hardware memory access patterns and tensor shape alignments appeared to bottleneck the pruned graph execution just as severely as the dense model. Furthermore, manual inspection of the dependency propagation trace revealed that certain convolutional blocks retained unpruned channels because skip connections bypassed the pruning mask propagation, leading to tensor dimension mismatches during runtime forward passes. We need to systematically analyze dependency graphs, reconstruct propagation rules on a toy network without importing heavy deep learning runtimes directly into the harness, apply structured pruning to a real CNN model using logged execution profiles, and measure the gap between theoretical structured pruning sparsity and real hardware speedup behavior.
