Specifically, the system crashes when processing text-only inputs because the multimodal projection pipeline unconditionally expects vision-specific configuration keys and image token placeholders to be present within the model architecture definition and the incoming prompt structure. This causes a KeyError or a shape mismatch exception deep inside the tensor sequence concatenation functions. Engineers need to reproduce this exact failure mode, design a robust verification routine that derives expected image-token counts correctly from patch dimensions and resolution parameters, and finally validate that the headless chat UI server smoke test correctly boots up and acknowledges requests without throwing unhandled exceptions. Fixing this will ensure that edge deployments can handle heterogeneous model types reliably.
