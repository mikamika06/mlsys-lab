When applying unstructured magnitude pruning to our transformer models to shrink memory footprints and test inference latency improvements, we notice peculiar behavior. Despite setting a global sparsity target of 90% across weight tensors using L1 magnitude criteria, the resulting compressed models fail to achieve any wall-clock inference speedups when evaluated on standard CPU hardware. Furthermore, using a simplistic uniform sparsity layer-by-layer allocation strategy leads to catastrophic accuracy drops in earlier embedding-adjacent layers, whereas more sophisticated reallocation approaches like Erdos-Renyi scaling struggle to precisely hit the global parameter count constraints without floating-point rounding discrepancies or off-by-one errors in mask creation. Engineers are reporting that naive implementations either violate the exact global sparsity percentage or produce dense emulation overhead that neutralizes any sparse execution benefits. We need a robust implementation that correctly computes global L1 unstructured masks to exact target sparsity, accurately models or measures the lack of speedup on unstructured sparsity on CPUs due to memory access patterns and sparse kernel overhead, and correctly implements both uniform and Erdos-Renyi per-layer sparsity allocations.
