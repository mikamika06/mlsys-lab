When serving large language models with variable sequence lengths (varlen) using dynamic batching and advanced compilation pipelines, production systems frequently experience severe performance degradation and latency spikes. During autoregressive generation phases, alternating token lengths and ragged tensor layouts cause continuous cache invalidations inside the compilation engine. Each unique sequence length signature triggers a brand-new graph compilation pass, halting execution for multiple seconds and saturating CPU cores with redundant lowering tasks. Furthermore, attempting to record a fixed-size CUDA graph for a decode step fails when input tensors change dimensions dynamically, leading to shape mismatch exceptions or invalid memory re-use. Inference services exhibit erratic throughput, high tail latencies, and severe GPU memory fragmentation under multi-tenant production traffic. Engineers need a robust mechanism to quantify recompilation events, enforce deterministic shape bucketing policies, and correctly manage CUDA graph capture for variable-length decoding workloads without sacrificing generation correctness or incurring prohibitive compilation overheads.
