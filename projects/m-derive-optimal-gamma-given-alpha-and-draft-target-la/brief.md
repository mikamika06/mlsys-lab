Our speculative decoding pipeline in the serving engine is underperforming on varied workloads because the draft length (gamma) is currently statically pinned to 4. When we deploy models where the draft-to-target latency ratio fluctuates or where the acceptance rate alpha varies wildly across different prompt domains, a fixed draft length leads to sub-optimal throughput. Sometimes the draft model wastes cycles proposing tokens that are constantly rejected, and other times we leave speedup on the table by not drafting enough candidates when the target model is exceptionally fast relative to the draft.

We need a complete mechanism for optimal draft length tuning. Specifically, we need to analytically derive the optimal gamma given alpha and the draft-to-target latency ratio, empirically sweep gamma from 1 to 8 using Hugging Face assisted generation to measure real tokens per second against a synthetic test harness, and finally implement an adaptive acceptance-streak-based heuristic that dynamically adjusts gamma at runtime without expensive overhead. Your task is to implement the core mathematical derivation, the empirical sweep benchmarker, and the adaptive heuristic in our spec library, ensuring that regressions are rigorously caught by your own test suite.
