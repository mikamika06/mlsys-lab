We are experiencing a discrepancy when trying to evaluate and compare real Mixture of Experts (MoE) model configurations that implement shared and fine-grained expert routing mechanisms in our low-level serving infrastructure.

In modern high-efficiency language models, traditional routing assigns tokens to coarse, isolated expert blocks. However, recent architectures adopt fine-grained expert routing coupled with shared experts, which factorize the feed-forward network layers into much smaller sub-experts and a dedicated shared trunk. When our current pipeline tries to parse, normalize, and compare memory footprints, compute intensity ratios, and effective parameter scaling across these real model configurations, the comparison metrics yield inconsistent or invalid outputs. This causes downstream scheduling and hardware sizing tools to miscalculate memory allocations and memory bandwidth requirements during kernel execution.

Your task is to implement the comparison and analysis utility module that correctly ingests these disparate MoE configurations, computes their exact effective parameters, evaluates shared versus fine-grained activation ratios, and produces verifiable metrics matching the reference oracle. You must also write a comprehensive regression test suite that catches subtle misconfigurations in expert sharing factors and routing dimensions.
