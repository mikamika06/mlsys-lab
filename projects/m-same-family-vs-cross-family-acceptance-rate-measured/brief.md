The speculative decoding pipeline in our serving infrastructure is currently experiencing unpredictable speedups when switching between different draft and target model combinations. Specifically, production telemetry indicates that cross-family draft configurations—where a smaller draft model from one architecture or lineage is paired with a flagship target model of an entirely different lineage—frequently suffer from suppressed token acceptance rates. This mismatch leads to excessive rollout rejections and wastes valuable accelerator compute cycles on redundant forward passes. Conversely, same-family draft-target pairings maintain stable, high acceptance rates, but our offline evaluation harness currently lacks a standardized local measurement module to systematically quantify, parse, and compare these performance profiles from raw generation traces. Without a reliable offline metric to evaluate same-family versus cross-family acceptance rates locally, engineering teams cannot automatically validate draft model selections before deployment or detect regressions when tuning speculative generation budgets and lookahead parameters. We need a dedicated metrics and evaluation package that processes verification trace logs, computes empirical local acceptance rates, classifies pairing performance characteristics, and enforces rigorous regression tests to ensure robust speculative execution across diverse model families.
