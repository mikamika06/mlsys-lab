An inference server running structured generation alongside speculative decoding has run into a subtle throughput degradation in production. The engine uses a speculative decoding pipeline where a faster draft model proposes sequences of tokens, and a target model validates them. However, when a strict JSON-key grammar constraint is active, the draft model—which has no awareness of the structural grammar state—frequently proposes tokens that violate the required syntax mask at various positions within the draft window.

Currently, the acceptance pipeline treats the draft sequence naively, leading to premature rejection or misalignment when grammar violations occur, even though some initial subset of the proposed draft tokens might be completely valid before hitting the first disallowed token. We need to implement a grammar-masked draft acceptance and recovery mechanism that correctly processes the draft tokens against the grammar mask, determines the exact valid accepted length, and recovers the correct prefix. Furthermore, engineers need tools to measure the real acceptance loss introduced by using an unmasked draft under a JSON-key grammar constraint, as well as a diagnostic mechanism to identify silent acceptance collapses caused by grammar mismatches between runs. You are tasked with implementing the core modules, the diagnostic routines, and a robust regression test suite to safeguard the acceptance and recovery logic against silent regressions.
