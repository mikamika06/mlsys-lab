An inference server running structured generation alongside speculative decoding is experiencing a subtle throughput degradation. The engine uses a speculative decoding pipeline where a faster draft model proposes sequences of tokens, and a larger target model validates them. However, when strict JSON-key grammar constraints are active, the draft model—which lacks full awareness of the structural grammar state—frequently proposes tokens that violate the required syntax mask at various positions within the draft window.

Currently, the acceptance pipeline evaluates the draft sequence naively, often misaligning or incorrectly advancing the state when a grammar violation occurs mid-draft, even if the initial subset of proposed tokens was perfectly valid. We need to implement a grammar-masked draft acceptance and recovery mechanism that explicitly checks draft tokens against the grammar mask, determines the exact valid accepted length, and properly truncates the sequence.

Furthermore, engineers need tools to measure the real acceptance loss caused by using unmasked drafts under JSON-key grammar constraints, as well as a diagnostic function to determine which of two real runs silently collapsed its acceptance rate due to a grammar mismatch. You are tasked with implementing these core mechanisms and a robust regression test suite to safeguard the logic against future silent regressions.
