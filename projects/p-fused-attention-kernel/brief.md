When executing transformer models with long context lengths, GPU performance drops significantly during the self-attention computation phase. Profiling reports indicate that execution units spend an excessive amount of idle time waiting for data rather than performing floating-point operations. Specifically, memory throughput metrics show massive traffic spikes involving global memory reads and writes of intermediate attention score matrices that scale quadratically with the sequence length.

During standard multi-head attention execution, computing the raw score matrix $QK^T$ requires writing substantial intermediate tensors to high-bandwidth memory. Subsequent softmax operations read these tensors back, compute exponential and reduction sums, and write out probability matrices, which are then read once more to compute the weighted sum with the value tensor $V$. This multi-pass memory round-trip behavior completely saturates available memory bandwidth long before reaching the theoretical peak compute capacity of modern tensor cores.

Engineers working on low-level machine learning systems observe severe latency regressions and out-of-memory bottlenecks when scaling sequence lengths beyond standard thresholds. The hardware fails to sustain high utilization because kernel execution is entirely bound by memory latency and bandwidth limits rather than arithmetic intensity. Resolving this performance degradation requires reorganizing the execution pattern to process blocks concurrently while maintaining numerical stability and correctness across all sequence configurations.
