We are experiencing unexpected precision degradation and memory overhead when performing large matrix multiplications with transformer models in production, specifically when down-casting or quantizing activation tensors. During high-throughput inference runs, standard lower-precision numerical representations like FP16 or BF16 preserve enough range, but naive INT8 quantization causes severe perplexity spikes and outlier accumulation, which completely degrades downstream accuracy on longer context lengths.

The primary issue stems from the uniform scaling applied across hidden states without accounting for persistent, systematic feature dimensions that consistently exhibit extreme magnitudes across tokens. These systemic outliers dominate specific channels, making standard absolute-maximum scaling compress the vast majority of non-outlier values down to zero or near-zero resolution, wiping out the signal for standard weights.

We need to implement the foundational mixed-precision decomposition technique introduced by LLM.int8(). This involves identifying feature-wise outlier dimensions based on a configurable threshold, separating those outlier channels to retain high precision (e.g., FP16), and casting the remaining non-outlier bulk into vector-wise scaled INT8 matrices to perform efficient integer matrix multiplication before recombining the partial results. Additionally, we need to empirically analyze how the outlier-fraction curve behaves as a function of the threshold parameter, and correctly derive vector-wise INT8 quantization scales for accurate dequantization.
