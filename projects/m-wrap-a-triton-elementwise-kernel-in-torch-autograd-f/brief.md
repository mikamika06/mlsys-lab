An inference server optimization initiative has hit a wall during the integration of a custom Triton elementwise kernel into a PyTorch model's forward and backward pass. The team is trying to fuse the activation function and a scaling operation to reduce memory bandwidth overhead on GPU.

However, during end-to-end model training, the pipeline is raising intermittent runtime errors and failing gradient checks. Specifically, when running standard `torch.autograd.gradcheck`, the system throws gradient mismatch exceptions. Furthermore, when intermediate tensors computed inside the forward pass are dropped or not explicitly preserved via the context, the backward pass fails catastrophically with missing attribute errors or incorrect gradient values. The engineering team needs a robust implementation of a custom `torch.autograd.Function` wrapper around a Triton kernel that correctly saves activations, computes the analytic derivative of the fused operation, and passes strict numerical gradient validation tests.
