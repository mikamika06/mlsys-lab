When building an optimized TensorRT deployment pipeline or inspecting exported ONNX graph topologies directly from raw binary streams, parsing the underlying Protocol Buffers wire format without relying on a full high-level compiler package can become a subtle bottleneck. In certain stripped-down, lightweight systems environments or custom model-analysis tooling, engineers encounter situations where high-level parsers fail or are unavailable, requiring raw binary interpretation of the ONNX ModelProto format.

Recently, during deployment integration tests for large multimodal models exported to ONNX, our binary inspection harness experienced persistent extraction failures when reading multi-gigabyte models containing split initializer files and external data references. The low-level parsing routines failed to correctly decode varint-encoded tags, separate graph node attributes from initializer tensors, and accurately extract the byte boundaries between the embedded graph topology and external weights payloads stored in separate files or trailing byte streams. Without a clean, self-contained way to wire-decode the ONNX ModelProto graph structure, parse the initializer manifest dump, and precisely split the weights-vs-graph bytes, parsing routines either crash on unknown wire types or misinterpret tensor data payloads.

Your task is to implement a lightweight, robust pure-Python and NumPy module that manually parses the ONNX binary wire format for a ModelProto graph, extracts the initializer metadata and tensor manifests, and correctly isolates the weights from the structural graph bytes without depending on external protocol buffer compiler runtimes.
