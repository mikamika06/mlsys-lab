We are experiencing significant performance instability and unpredictable latency spikes when running compilation workflows for our low-level deep learning models on modern CPU and GPU architectures. Specifically, production engineers have noticed that when enabling max-autotune optimization modes for high-throughput matrix multiplication blocks, the compilation overhead can increase dramatically while the resulting runtime latency profiles fail to match expected speedup targets. Furthermore, when analyzing performance regression logs generated by our GPU kernel benchmarking harness, identifying the optimal configuration key manually from extensive autotuning logs is error-prone and slows down our automated deployment pipelines. Additionally, when inspecting execution traces collected during reduced-overhead inference runs, identifying the precise timestamps and boundaries of CUDA graph recapture events becomes difficult, leading to missed opportunities for tracking memory reuse efficiency and kernel launch latency reductions across dynamic workloads. Your task is to implement the necessary analysis utilities to reliably parse autotuning logs, compute performance and compilation time ratios, and locate graph recapture events within execution traces, ensuring our low-level compilation stack operates predictably and efficiently.
