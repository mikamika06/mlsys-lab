We are seeing intermittent stalls during distributed data loading in our training pipeline, particularly when scaling up the batch size and worker count across multiple nodes. The infrastructure monitoring shows periods where GPU compute utilization drops significantly, while host CPU usage spikes briefly and disk read throughput hits plateaus.

Engineers have captured raw profiling artifacts from the runtime, specifically containing OS-level system trace summaries (`osrt_sum`) and NVTX range push/pop event streams from the host threads. However, the raw text dumps are massive, unstructured, and difficult to inspect manually to isolate the root cause of the data-loading stalls.

Your task is to build a diagnostic utility that parses and analyzes these real OS-level profiling traces. Specifically, you need to reconstruct the hierarchical NVTX range nesting depth over time from flat push/pop event tables, compute duration statistics, and identify anomalous data-loader I/O bottlenecks where blocking file operations starve the training loop. You must also write a regression test suite that validates your parsing logic against edge cases like unbalanced push/pop markers.
