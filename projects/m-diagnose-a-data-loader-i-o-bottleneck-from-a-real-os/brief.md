# Data Loader Pipeline Analysis and NVTX Range Reconstruction

Our distributed training pipeline experiences severe, intermittent stall periods where GPU kernel launch queues dry up completely. Profiling traces generated by Nsight Systems (`nsys stats --report osrt_sum`) exhibit high latency across multiple operating system runtime syscalls, but performance engineers cannot easily correlate raw syscall summary statistics with application-level data loading stages. Furthermore, flat NVTX push/pop event traces exported from SQLite report tables lack explicit stack depth tracking, making it impossible to analyze time spent in nested preprocessing blocks.

To resolve these issues, you will implement an automated diagnostic module that analyzes raw OS runtime summaries and reconstructs active NVTX call stacks over time.

## Goal
Implement diagnostic routines in `nsys_diag` to parse `osrt_sum` syscall metrics, categorize system-level wait times, and reconstruct NVTX call stack depth timelines from flat push and pop annotation records.

## Requirements
1. **OSRT Bottleneck Diagnosis (`nsys_diag/osrt.py`)**:
   - `categorize_syscall_time(osrt_rows)`: Group total execution duration across raw `osrt_sum` rows into file I/O operations (`read`, `pread64`, `write`, `pwrite64`, `open`, `openat`, `close`, `fsync`, `fdatasync`), synchronization primitives (`futex`, `epoll_wait`, `epoll_pwait`, `poll`, `select`, `sem_wait`, `pthread_cond_wait`), and remaining system calls.
   - `diagnose_osrt_bottleneck(osrt_rows)`: Compute the ratio of I/O wait time relative to overall system call overhead. Identify if the process is I/O-bound (I/O ratio $\ge 0.50$) or dominated by thread synchronization/CPU compute.

2. **NVTX Nesting Depth Timeline (`nsys_diag/nvtx.py`)**:
   - `reconstruct_nvtx_depths(events)`: Sort flat push/pop events chronologically and track explicit call stack depth per timestamp. Raise `ValueError` if a `pop` event occurs on an empty stack or if unclosed `push` events remain at the end of the trace.
   - `analyze_nvtx_nesting(events)`: Calculate the maximum active nesting depth and aggregate the total elapsed nanoseconds spent at each stack depth level (> 0).

3. **Regression Safety Net (`tests/test_regression.py`)**:
   - Write unit tests that verify `reconstruct_nvtx_depths` correctly raises `ValueError` when evaluated against mismatched or malformed push/pop event lists.
