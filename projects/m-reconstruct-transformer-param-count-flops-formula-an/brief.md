When configuring compressed student architectures for distilled large language models, teams often notice severe discrepancies between theoretical parameter count reductions and actual operational memory or runtime bottlenecks. Specifically, naive application of depth pruning versus width pruning yields vastly different day-0 loss curves and gradient behaviors, yet existing configuration scripts fail to accurately project parameter counts or validate structural invariants. Engineers report that standard initialization strategies (such as random, layer stacking, or truncated copying) produce erratic initial loss spikes that derail subsequent distillation runs before training even begins. Furthermore, missing regression tests allow invalid structural configurations to pass silently, causing failures in automated pruning and distillation pipelines. This exercise unit guides you through reconstructing analytical parameter and FLOP count formulas, benchmarking day-0 initialization losses across multiple strategies, and enforcing structural comparison invariants via a robust test suite.
