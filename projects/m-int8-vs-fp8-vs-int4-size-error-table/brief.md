We've provided the exact E4M3 representable values and a nearest-neighbor mapping function in `fp8.py` so you can focus on the core logic. The standard symmetric quantization for INT8 and INT4 needs to be correctly formulated alongside the MSE evaluation.

We need to clearly measure the error gap between in-domain and out-of-domain calibration scales on the activations. Calibrating on domain B but deploying on domain A should yield significantly worse MSE than calibrating on domain A.

We suspect a few massive outlier activations are poisoning the max-calibration scales, squeezing all the normal signal into zero. We need a robust outlier-poisoning detector that flags the calibration tensor if any channel's max absolute value is suspiciously larger than its 99th percentile (e.g., > 10x).
