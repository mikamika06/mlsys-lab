# FP8 E4M3 codec, scaling, and format comparison

During recent model integration experiments, the low-precision inference pipeline exhibits severe accuracy degradation and sudden numerical instability when processing transformer activations with prominent long tails. Downstream tasks show catastrophic perplexity spikes, and intermediate layer outputs frequently collapse to zero or saturate prematurely due to improper handling of near-zero values and subnormal representations.

Inspection of the telemetry reveals that raw float32 tensors are currently cast using naive clipping without dynamic per-tensor scaling factors optimized for the E4M3 dynamic range. Furthermore, the custom quantization routines fail to correctly encode and decode subnormal values in the E4M3 format, creating artificial dead zones that destroy fine-grained gradient and activation dynamics close to zero. When comparing E4M3 against E5M2 and integer 8-bit formats on long-tailed distributions, the lack of a robust codec and scaling implementation leads to unbounded quantization error. Your task is to implement a correct E4M3 codec supporting subnormals, derive optimal per-tensor scaling factors, and build rigorous verification tests to ensure numerical fidelity across different precision formats.
