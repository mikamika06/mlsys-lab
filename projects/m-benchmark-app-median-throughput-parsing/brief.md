In our continuous integration pipeline for low-level ML systems, we run CPU inference experiments daily to ensure performance hasn't regressed. We use OpenVINO's `benchmark_app` to measure system behavior under two distinct modes: latency-bound (using `-hint latency`) and throughput-bound (using `-hint throughput`). Currently, the results are dumped as raw text logs, making it nearly impossible to quickly visualize trends or alert on performance regressions because the metrics are buried in standard output.

Your task is to build a robust parser that extracts key numerical metrics from these logs. First, you need to parse the standard benchmark output to reliably extract the Throughput (in FPS) and the Median Latency (in ms). You will also create a comparison helper that parses two distinct hint reports and consolidates them into a single dictionary.

Next, you will parse the performance counters report (generated by appending `-pc` to the command). This report is a tabular output showing execution time per layer. Because models can have thousands of layers, we only care about the top 5 most computationally expensive layers. You must extract their names and execution times (in milliseconds), sorting them from slowest to fastest.

Finally, write a regression test to ensure that the performance counters are always sorted correctly, safeguarding against future code changes that might accidentally invert the sorting order or parse the wrong metrics.
