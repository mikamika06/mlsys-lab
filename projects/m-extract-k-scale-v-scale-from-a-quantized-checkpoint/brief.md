We are running into scaling discrepancies when preparing our quantized key-value caches for inference serving under memory-constrained environments. During our recent profiling runs of large language model serving pipelines using llm-compressor calibration routines, we observed that the extracted scaling factors for key and value tensors do not match the expected dynamic ranges observed during active token generation.

Specifically, when pulling `k_scale` and `v_scale` parameters directly from quantized checkpoints generated via absmax calibration on cached activation states, downstream kernel execution encounters precision degradation and unexpected saturation. Furthermore, when sweeping across different calibration sample counts to evaluate scale stability, the resulting quantization scales exhibit high variance, suggesting that the underlying extraction or sample accumulation logic is either improperly aggregating tensor statistics or failing to capture the correct absolute maximum boundaries across sequence lengths.

We need to implement a robust pipeline module that extracts these calibration scales accurately from the checkpoint state dicts, correctly reproduces the absmax calibration procedure using cached activations, and performs a systematic sample-count sweep to verify scale stability without introducing numerical drift or shape mismatches.
