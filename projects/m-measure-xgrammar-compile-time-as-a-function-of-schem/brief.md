# Ticket: High Latency and Validation Failures in Guided Decoding Pipelines

During recent load testing of our structured output serving tier using vLLM alongside JSON schema constraints, several critical performance and correctness anomalies have surfaced. Specifically, serving latency spikes intermittently when handling nested object schemas, and certain complex schemas fail during tokenizer vocabulary masking phases or produce unexpected validation errors downstream.

Engineers report that compiling deep or highly branching JSON schemas introduces non-trivial overhead before token generation even begins. Furthermore, when comparing token masks generated by our state-machine engine against the external xgrammar library integration, divergence occurs on edge cases involving unconstrained string types, optional fields, and unsupported keyword combinations. This leads to invalid tokens being unmasked or valid tokens being prematurely filtered out, causing generation stalls or schema conformance failures.

Additionally, client-provided schemas frequently contain unbounded strings, regex patterns, or advanced JSON schema constructs that cause the compilation pipeline to throw internal errors or degrade token generation throughput severely. We need a robust diagnostic and transformation toolkit to analyze schema compilation scaling, accurately compute and cross-verify token masks against reference FSM behaviors, and deterministically rewrite complex schemas into constraint-friendly equivalents without altering underlying validation semantics.
