When evaluating post-training quantization on our transformer block weights, we noticed a severe degradation in output fidelity when moving from full precision to 4-bit weights using standard round-to-nearest (RTN) methods. Specifically, running a simple linear layer transformation with a 64x64 weight matrix results in output mean squared error metrics that spike drastically beyond acceptable thresholds, causing downstream validation perplexity to collapse during generation tasks. Profiling the layer activations and weight updates reveals that quantization errors accumulate systematically across columns rather than averaging out to zero, because the cross-column correlations encoded in the input Hessian are completely ignored during independent rounding. While the naive truncation approach is fast, it fails to compensate for the redistribution of residual errors into unquantized weights, leading to biased activations in subsequent linear projections. We need a robust implementation of the Optimal Brain Quantization (OBQ) / GPTQ sequential error-compensation mechanism for a single 64x64 weight layer to properly absorb residual quantization noise via inverse Hessian updates, ensuring that the quantized layer output closely tracks the full-precision baseline without catastrophic error propagation.
