We are integrating a vision-language model into a low-level serving framework, but the underlying transformer backend uses a flexible architecture where different submodules can have distinct attention configurations. Specifically, vision encoder layers, cross-modal projector layers, and text decoder layers each require their own distinct attention mechanisms, block sizes, and head configurations.

Currently, the serving engine crashes when initializing the attention planner because it assumes a homogeneous attention configuration across all submodules in the model. When loading a multimodal checkpoint, the initialization pipeline fails to parse the per-submodule attention overrides defined in the configuration dictionary, leading to mismatched tensor dimensions during KV cache allocation and kernel dispatch.

Your task is to implement a per-submodule attention configuration parser and validator for Vision-Language Models. You need to parse submodule-specific attention parameters from the model configuration, compute memory footprints accurately based on these heterogeneous configurations, and write a robust regression test suite that catches any misrouted submodule attention layers.
