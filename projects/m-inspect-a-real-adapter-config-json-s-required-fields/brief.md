Furthermore, we are trying to serve multiple tenants on a single GPU by attaching two named real LoRA adapters to one base model and switching between them via `set_adapter`. However, inference requests for different tenants are coming out completely identical, as if the active adapter isn't actually being swapped in the forward pass.

Please build an inspection utility (`inspect_config` in `peft_mechanics/config.py`) that returns missing or corrupted fields in `adapter_config.json`. Then, implement a minimal multi-adapter router (`AdapterRouter` in `peft_mechanics/router.py`) that correctly loads configurations, tracks the active adapter, and applies the active LoRA weights over the base model, ensuring that `set_adapter` reliably changes the computation graph.
