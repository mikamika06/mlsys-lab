When deploying large language models or multimodal vision-language architectures under severe hardware memory limits, engineers rely on quantization schemes to compress weights and reduce bandwidth consumption. However, accurately determining the exact fraction of parameters that undergo quantization becomes surprisingly complex when models incorporate heterogeneous components. Specifically, multimodal architectures feature distinct vision encoders, projection layers, and cross-attention blocks alongside the core language model backbone, and operators frequently need to restrict quantization exclusively to the language model body while leaving multimodal components unquantized.

In our production serving stack, we recently identified a performance regression where memory usage failed to match our projected compression rates. Profiling revealed two main culprits: first, ignore lists and scope filters were incorrectly sweeping in multimodal vision components or failing to apply language-only target constraints; second, the high-capacity language model head (`lm_head`)—which represents a massive fraction of total model parameters due to large vocabularies—was either being omitted from weight reduction calculations or mispriced regarding its memory footprint.

Your task is to build a module targeting and parameter quantification library that correctly inspects model configurations, respects language-only scope restrictions in multimodal setups, calculates exact parameter counts and fractions, and accounts for the memory cost of the `lm_head`. You must implement the targeting filters, metric computations, and an analysis pipeline accompanied by a robust regression test suite that catches improper scope relaxation or missing head calculations.
