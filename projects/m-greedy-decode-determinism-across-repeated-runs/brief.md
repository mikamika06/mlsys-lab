Engineers working with OpenVINO GenAI LLMPipeline on CPU inference have noticed unexpected divergence in multi-run generational tasks. When executing greedy-decode generation multiple times sequentially using the exact same prompt, model weights, and decoding parameters, some runs yield different output token sequences, or display irregular per-token latency profiles between a cold restart and a cache-reused run. Specifically, the first token or subsequence generated during a clean restart runs with a different latency characteristic compared to subsequent runs where the KV cache or state context is retained or reused in memory. This inconsistency undermines deterministic evaluations, replay logging, and exact regression tests. Your task is to investigate and implement the determinism controls, verify exact sequence matching across repeated greedy-decode runs, and track per-token latency variations between cold restarts and KV-cache-reused executions to guarantee stable, predictable low-level inference behavior under the OpenVINO GenAI pipeline runtime.
