We are experiencing a drop in speculative decoding throughput during concurrent serving under various batch sizes and trace lengths. The current implementation uses fixed hyperparameters for the draft model and number of speculative tokens, which fails to adapt to changing GPU memory bandwidth, compute constraints, and acceptance rates across diverse workloads. When serving models under concurrency levels ranging from 1 to 64, static configurations result in suboptimal tokens per second, sometimes performing worse than vanilla autoregressive generation due to wasted verification overhead.

We need to optimize our speculative decoding pipeline to dynamically maximize predicted tokens per second. This requires implementing a model for evaluating optimal speculative token counts across four distinct models, incorporating prompt-lookup or ngram drafting mechanisms to measure acceptance rates accurately on a real code-edit trace, and developing a rigorous go/no-go decision framework for speculation across concurrency tiers 1, 4, 16, and 64. The updated system must ensure robust verification through automated regression testing that guarantees correctness under dynamic token selection.
